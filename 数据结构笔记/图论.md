# 图论
#### 拓扑排序（Topological Sort）
>**只针对有向无环图 DAG（Directed Acyclic Graph）**
核心：把图里所有顶点排成一个线性序列，满足：**图中每一条有向边 u → v，在序列里 u 一定出现在 v 的前面**。
如果图存在环，**不存在拓扑序**。
如果图 G 是有向无环图，那么它的**拓扑排序可能不止一种**。举一个最极端的例子，如果图 G 值包含 n 个节点却没有任何边，那么任意一种编号的排列都可以作为拓扑排序。


>代码实现：
- 
  ```cpp
  vector<int> topo(int n, vector<vector<int>>& adj, vector<int>& in_deg)
  {
      queue<int> q;
      vector<int> res;
      for(int i=0;i<n;i++){
          if(in_deg[i]==0) q.push(i);
      }
      while(!q.empty()){
          int u = q.front(); q.pop();
          res.push_back(u);
          for(int v:adj[u]){
              in_deg[v]--;
              if(in_deg[v]==0) q.push(v);
          }
      }
      return res;
  }
  ```
