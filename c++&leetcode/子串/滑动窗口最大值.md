- 题目:
  给你一个整数数组 nums，有一个大小为 k 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 k 个数字。滑动窗口每次只向右移动一位。
  返回 滑动窗口中的最大值 。
- 示例:
  示例 1：
  输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
  输出：[3,3,5,5,6,7]
  解释：
  滑动窗口的位置                最大值
  ---------------               -----
  [1  3  -1] -3  5  3  6  7       3
  1 [3  -1  -3] 5  3  6  7       3
  1  3 [-1  -3  5] 3  6  7       5
  1  3  -1 [-3  5  3] 6  7       5
  1  3  -1  -3 [5  3  6] 7       6
  1  3  -1  -3  5 [3  6  7]      7
  示例 2：
  输入：nums = [1], k = 1
  输出：[1]
---
- 思路:
  见注释
- 代码:
  ```cpp
  class Solution {
  public:
      vector<int> maxSlidingWindow(vector<int>& nums, int k) {
          //怎么感觉有点印象
          //维护一个最大最晚的栈
          //把当前值和栈顶比较，如果比它大就直接弹出，直到空或者栈顶更大了，就入栈
          //因为后进的一定更晚出窗口，比它早且比他小的没用
          //如果栈底被移除窗口，则把栈底弹出，当前最大值是新栈底
          deque<int> dq;
          vector<int> res;
          for(int i = 0,j=0;j<nums.size();j++){
              while(!dq.empty()&&nums[j]>dq.back()){
                  dq.pop_back();
              }
              dq.push_back(nums[j]);
              
              
              if(j-i+1 == k){
                  //窗口滑动
                  res.emplace_back(dq.front());
                  if(nums[i] == dq.front()) dq.pop_front();
                  i++;
              }
          }
          return res;
      }
  };
  ```
- 结果:
  时间42,空间54
- 复杂度分析
  外层循环是n
  里面嵌套了while循环,但是其所有pop操作最多是n次,
  加起来是2n
  时间复杂度O(n)

**根据ai的提示的优化**
- 思路
  可以直接在双端队列里存下标
  遇到相同值时也可以直接弹出,因为存的一定是更靠后的
- 代码:
  ```cpp
  class Solution {
  public:
      vector<int> maxSlidingWindow(vector<int>& nums, int k) {
          deque<int> dq;
          vector<int> res;
          for(int i = 0,j=0;j<nums.size();j++){
              while(!dq.empty()&&nums[j]>=nums[dq.back()]){
                  dq.pop_back();
              }
              dq.push_back(j);
              
              if(j-i+1 == k){
                  //窗口滑动
                  res.emplace_back(nums[dq.front()]);
                  if(i == dq.front()) dq.pop_front();
                  i++;
              }
          }
          return res;
      }
  };
  ```
- 结果:
  时间92,空间44
  话说原来这题就是那个杀老员工的,印象深刻

**题解的做法一(堆)**
- 思路
  维护一个大顶堆,堆内元素为pair类型,存[值,下标]
  如果当前堆顶下标在窗口内,则当前最大值就是它的值
  如果不在窗口内,则移除,因为可能记录了一个很早以前的值,所以要继续判断当前堆顶是不是在窗口内
  直到是在窗口内,记录其值
  用的是c++自带的堆类型(叫优先队列),插入和删除会自己确保堆的结构
- 代码:
  ```cpp
  class Solution {
  public:
      vector<int> maxSlidingWindow(vector<int>& nums, int k) {
          int n = nums.size();
          priority_queue<pair<int, int>> q;
          for (int i = 0; i < k; ++i) {
              q.emplace(nums[i], i);
          }
          vector<int> ans = {q.top().first};
          for (int i = k; i < n; ++i) {
              q.emplace(nums[i], i);
              while (q.top().second <= i - k) {
                  q.pop();
              }
              ans.push_back(q.top().first);
          }
          return ans;
      }
  };
  ```
