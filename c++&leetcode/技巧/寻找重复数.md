**题解的做法一(二分法)**
- 思路
  本题的约束条件非常严格：不能修改原数组 且 只能使用常数空间。这排除了排序、哈希表等常规思路。
  一个非常巧妙的解法是对数字的范围而不是数组的索引进行二分查找。其核心思想是**抽屉原理（Pigeonhole Principle）**。
  抽屉原理：如果每个抽屉代表一个数字，每个元素代表一个苹果。现在有 n+1 个苹果要放到 n 个抽屉里，则至少有一个抽屉里会有两个苹果。
  算法步骤：
  - 确定搜索范围：数字的范围是 [1, n]，所以我们初始化 left = 1, right = n。
  - 进行二分查找：
  - 计算中间数 mid = (left + right) // 2。**这是在一个假想数组[1,n]中**
  - 遍历整个数组，统计所有小于等于 mid 的数字的个数 count。
  - 判断并缩小区间（这是最关键的一步）：
  - 如果 count <= mid：
    说明 [1, mid] 这个区间内的数字“没有超额”，所有重复数字都正常出现了。
  - 根据抽屉原理，重复数必然在 [mid+1, right] 这个更大的区间里。
  调整左边界：left = mid + 1。
  - 如果 count > mid：
    说明 [1, mid] 这个区间内的数字“出现了超额”，重复数必然存在于这个区间内。
  - 调整右边界：right = mid（注意：mid 本身有可能是重复数，所以不能跳过）。
  - 循环结束：当 left == right 时，它们所指向的数字就是我们要找的重复数。

**题解的做法三(快慢指针)**
- 思路
  因为值为[1,n]
  所以可以利用num[i]跳转到nums[nums[i]]
  如果nums[i]指向的位置就是它自己在nums中的位置
  1. 它不是重复数字,则不会经过它
  2. 它是重复数字,则还有另一个nums[i]指向它,在它自身形成环
  因为下标是从0开始,而数字是1开始
  所以快慢指针从0出发必然不会回到0(即指向自身),不会自循环
- 快慢指针的公式
  我们先设置慢指针 slow 和快指针 fast ，慢指针每次走一步，快指针每次走两步，根据「Floyd 判圈算法」两个指针在有环的情况下一定会相遇，此时我们再将 slow 放置起点 0，两个指针每次同时移动一步，相遇的点就是答案。
- 代码:
  ```cpp
  class Solution {
  public:
      int findDuplicate(vector<int>& nums) {
          int slow = 0, fast = 0;
          do {
              slow = nums[slow];
              fast = nums[nums[fast]];
          } while (slow != fast);
          slow = 0;
          while (slow != fast) {
              slow = nums[slow];
              fast = nums[fast];
          }
          return slow;
      }
  };
  ```
