- 题目：
  给定一个大小为 n 的数组 nums ，返回其中的多数元素。多数元素是指在数组中出现次数 大于 ⌊ n/2 ⌋ 的元素。
  你可以假设数组是非空的，并且给定的数组总是存在多数元素。
  进阶：尝试设计时间复杂度为 O(n)、空间复杂度为 O(1) 的算法解决此问题。
- 示例：
  示例 1：
  输入：nums = [3,2,3]
  输出：3
  示例 2：
  输入：nums = [2,2,1,1,1,2,2]
  输出：2
---
- 思路：
  因为数量一定大于一半，所有可以排序，中间的一定是
- 代码：
  ```cpp
  class Solution {
  public:
      int majorityElement(vector<int>& nums) {
          sort(nums.begin(),nums.end());
          return nums[nums.size()/2];
      }
  };
  ```
- 结果:
  时间8,空间25
  题解的法二

**题解的做法五(投票法)**
- 思路:
  维护一个候选众数 candidate 以及它出现的次数
  遍历数组
  如果次数为0把当前值赋给candidate,次数++
  如果当前值与candidate相等,次数++
  如果不等,次数--
  如果次数为0把当前值赋给candidate,次数++
  这其实就相当于把每个数的次数都记录了
  因为众数的数量大于n/2,所以众数会把所有其他数的次数给减到0,遍历完后只有它会留下
- 代码:
  ```cpp
  class Solution {
  public:
      int majorityElement(vector<int>& nums) {
          int candidate = -1;
          int count = 0;
          for (int num : nums) {
              if (num == candidate)
                  ++count;
              else if (--count < 0) {
                  candidate = num;
                  count = 1;
              }
          }
          return candidate;
      }
  };
  ```
