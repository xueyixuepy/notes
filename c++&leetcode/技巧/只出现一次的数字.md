- 题目：
  给你一个 非空 整数数组 nums ，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。
  你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。
- 示例
  示例 1 ：
  输入：nums = [2,2,1]
  输出：1
  示例 2 ：
  输入：nums = [4,1,2,1,2]
  输出：4
  示例 3 ：
  输入：nums = [1]
  输出：1
---
- 思路：
  不用额外空间的话不太好去记录
  因为不是素数，感觉也没法用乘法
  感觉可以用排序，然后再遍历
  sort平均是O(nlogn)
  然后再遍历一遍是O(n)
  总时间复杂度是O(n+nlogn)
- 代码：
  ```cpp
  class Solution {
  public:
      int singleNumber(vector<int>& nums) {
          sort(nums.begin(),nums.end());
          for(int i = 0;i<nums.size();i++){
              if((i-1>=0&&nums[i-1]==nums[i])||(i+1<nums.size()&&nums[i+1]==nums[i])){
              }
              else{
                  return nums[i];
              }
          }
          return nums[0];//这是随便返回的,其实没有也可以,但是会报错
      }
  };
  ```
- 结果:
  时间100,空间50
---
**题解的做法**
- 思路:
  使用异或运算对数字的每一位进行异或.
  如果数字相等,则得到0,
  任何数异或0得到它本身
  从头到尾异或一遍,最后的数就是只出现一次的
- 代码:
  ```cpp
  class Solution {
      public int singleNumber(int[] nums) {
          int single = 0;
          for (int num : nums) {
              single ^= num;
          }
          return single;
      }
  }
  ```
- 复杂度
  时间O(n)
