- 题目：
  给你一个字符串 s，找到 s 中最长的回文子串。
- 示例：
  示例 1：
  输入：s = "babad"
  输出："bab"
  解释："aba" 同样是符合题意的答案。
  示例 2：
  输入：s = "cbbd"
  输出："bb"
---
- 思路：
  见代码注释
- 代码：
  ```cpp
  class Solution {
  public:
      string longestPalindrome(string s) {
          //这是二维动态规划
          //于是f(i,j)表示s[i:j+1]是回文串
          //那么f(i,j) = f(i+1,j-1)&&s[i]==s[j]
          //关键在于怎么去遍历，使得每次的i，j都有已经记录的i-1，j+1
          //单指针毫无疑问不行
          //双指针顺序遍历，也不行
          //于是我想到让双指针发散的方式，
          //定义两个指针，一个快，一个慢，
          //当快的和慢的指向同一个位置，则向外发散，判断以当前位置为中心的所有情况
          //然后快指针右移一格，再次发散
          //然后慢指针向右移
          //因为实际上所有的回文子串都能找到一个单独的中心或者连续的两字符作为中心。
          int slow = 0;
          int fast = 0;
          int maxSize = 0;
          vector<int> res(2);
          vector<vector<bool>> rem(s.size(),vector<bool>(s.size(),false));
          while(fast<s.size()){
              for(int left = slow,right = fast;left>=0&&right<s.size();left--,right++){
                  if(left == right){
                      rem[left][right] = true;
                  }
                  else if(left==right-1){
                      rem[left][right] = s[left]==s[right];
                  }
                  else{
                      rem[left][right] = rem[left+1][right-1]&&(s[left]==s[right]);
                  }
                  if(rem[left][right]&&right-left+1>maxSize){
                      maxSize = right-left+1;
                      res[0] = left;
                      res[1] = right+1;
                  }
              }
              if(slow == fast){
                  fast++;
              }
              else{
                  slow++;
              }
          }
          return s.substr(res[0],res[1]-res[0]);
      }
  };
  ```

  **【思路混乱：把「中心扩散法」和「动态规划法」硬捏在一起了】**
  这题本来就两套独立的解法，你现在把两套逻辑揉在一起，既冗余又容易写错：
  - 外层用 slow/fast 两个指针一替一步涨，本质是在枚举所有回文中心（奇数中心`(i,i)`、偶数中心`(i,i+1)`）—— 这是**中心扩散法**的枚举逻辑，但正常写根本不需要这么绕：直接循环 i 从 0 到 n-1，每次同时扩散 (i,i) 和 (i,i+1) 两个中心就行，没必要搞 slow/fast 交替这种花里胡哨的节奏。
  - 内层又硬套 DP 转移逻辑（`rem[i][j]`存区间是否回文）—— 但中心扩散法根本不需要开一个 O (n²) 的 DP 表，扩散过程中实时判断字符是否相等就行，开这个大表纯属浪费空间。

  本质上你是用 DP 表当扩散过程的临时标记，但完全没发挥 DP 的优势，反而把简单的流程写复杂了。

**题解的做法一(动态规划)**
- 思路:
  这个做法是按子串长度划分的
  先是判断为1的
  然后是为2的
  然后是3.....
- 代码:
  ```cpp
  #include <iostream>
  #include <string>
  #include <vector>

  using namespace std;

  class Solution {
  public:
      string longestPalindrome(string s) {
          int n = s.size();
          if (n < 2) {
              return s;
          }

          int maxLen = 1;
          int begin = 0;
          // dp[i][j] 表示 s[i..j] 是否是回文串
          vector<vector<int>> dp(n, vector<int>(n));
          // 初始化：所有长度为 1 的子串都是回文串
          for (int i = 0; i < n; i++) {
              dp[i][i] = true;
          }
          // 递推开始
          // 先枚举子串长度
          for (int L = 2; L <= n; L++) {
              // 枚举左边界，左边界的上限设置可以宽松一些
              for (int i = 0; i < n; i++) {
                  // 由 L 和 i 可以确定右边界，即 j - i + 1 = L 得
                  int j = L + i - 1;
                  // 如果右边界越界，就可以退出当前循环
                  if (j >= n) {
                      break;
                  }

                  if (s[i] != s[j]) {
                      dp[i][j] = false;
                  } else {
                      if (j - i < 3) {
                          dp[i][j] = true;
                      } else {
                          dp[i][j] = dp[i + 1][j - 1];
                      }
                  }

                  // 只要 dp[i][L] == true 成立，就表示子串 s[i..L] 是回文，此时记录回文长度和起始位置
                  if (dp[i][j] && j - i + 1 > maxLen) {
                      maxLen = j - i + 1;
                      begin = i;
                  }
              }
          }
          return s.substr(begin, maxLen);
      }
  };
  ```
- 解析
  不要搞错了,L是子串长度
  i才是左边界
- 复杂度分析:
  时空间都是O($n^2$)

**题解的做法二(中心扩展法)**
- 标准的d代码:
  ```cpp
  class Solution {
    public String longestPalindrome(String s) {
        if (s == null || s.length() < 1) {
            return "";
        }
        int start = 0, end = 0;
        for (int i = 0; i < s.length(); i++) {
            int len1 = expandAroundCenter(s, i, i);
            int len2 = expandAroundCenter(s, i, i + 1);
            int len = Math.max(len1, len2);
            if (len > end - start) {
                start = i - (len - 1) / 2;
                end = i + len / 2;
            }
        }
        return s.substring(start, end + 1);
    }

    public int expandAroundCenter(String s, int left, int right) {
        while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
            --left;
            ++right;
        }
        return right - left - 1;
    }
  }
  ```
