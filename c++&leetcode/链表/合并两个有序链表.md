- 题目
  将两个升序链表合并为一个新的 升序 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。
  - 输入：l1 = \[1,2,4], l2 = \[1,3,4]
  - 输出：\[1,1,2,3,4,4] 
---

- 之前想了挺久这题来着,这题还被归类为简单,这次做发现确实不难.
- 我的想法是两个指针,先把两个链表分好责任,首元素大的放list2,首元素小的放list1,对list1进行遍历,如果需要插入list2当前位置,就插入,否则移动list2当前节点指针,做好特殊情况的处理就好了.
- 遇到的问题是,我写移动now2的时候出了错,对每次循环都移动了,其实应该是没插入的情况下才移,然后没什么大问题

```cpp
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        if(list1==nullptr||list2==nullptr){
            return list1==nullptr?list2:list1;

        ListNode* tem1;
        ListNode* tem2;
        if(list1->val<list2->val){
            tem1 = list1;
            list1 = list2;
            list2 = tem1; 
        }
        ListNode* now1 = list1;
        ListNode* now2 = list2;
        ListNode* head1 = list1;
        ListNode* head2 = list2;
        while(now1!=nullptr&&now2!=nullptr){
            if(now1->val>=now2->val&&(now2->next==nullptr||now2->next->val>now1->val)){
                tem1 =now2->next ;
                now2->next = now1;
                now2 = now2->next;
                tem2 = now1->next;
                now1->next = tem1;
                now1 = tem2;
                
            }

            }
        }

    }
};
```

- 看了看评论区，发现一个特别简洁漂亮的写法，用的递归
  - 从最后两个链表都只有一个元素开始看，这个函数的作用就是把更大一方接在更小一方后面，每次调用都是确定当前节点的下一个节点指针，在递归的返回过程中，把最大的节点接在第二大的后面，第二大的又接在第三大的后面。
```cpp
struct ListNode* mergeTwoLists(struct ListNode* l1, struct ListNode* l2) {
    if(l1==NULL)
        return l2;
    if(l2==NULL)
        return l1;
    if(l1->val < l2->val){
        l1->next = mergeTwoLists(l1->next,l2);
        return l1;
    }else{
        l2->next = mergeTwoLists(l1,l2->next);
        return l2;
    }
}
```
