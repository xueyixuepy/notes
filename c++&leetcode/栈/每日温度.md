# 记录
- 题目：
  给定一个整数数组 temperatures ，表示每天的温度，返回一个数组 answer ，其中 answer[i] 是指对于第 i 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 0 来代替。
- 示例
  示例 1:
  输入: temperatures = [73,74,75,71,69,72,76,73]
  输出: [1,1,4,2,1,1,0,0]
  示例 2:
  输入: temperatures = [30,40,50,60]
  输出: [1,1,1,0]
  示例 3:
  输入: temperatures = [30,60,90]
  输出: [1,1,0]
- 思路：
  感觉用栈怎么都做不出来，因为入栈的时候，没法找到当前值的下一个最大值，最多记录最大值，出栈的时候，可能会把很早之前的一个大数的下一个最大值给去掉。
  所以我还是选择用列表记录一个关系当日->当日下一个最高温度日。
  从后往前处理。
  如果当日比下一日温度高，则递归寻找下一日的下一个最高温度日，直到找到的下一日的下一最高温度日是它本身。如果当日还是温度最高，则他的下一最高温度日是它本身。否则，在循环结束后找到了比当日温度高的日。
  如果当日比下一日温度低，则他的下一最高温度日是它的下一日
- 代码：
  ```cpp
  class Solution {
  public:
      vector<int> dailyTemperatures(vector<int>& temperatures) {
          int nextP;
          vector<int> p(temperatures.size());
          vector<int> res(temperatures.size());
          for(int j = temperatures.size()-1;j>=0;j--){
              if(j == temperatures.size()-1){
                  nextP = j;
                  p[j] = nextP;
              }
              else{
                  if(temperatures[j]<temperatures[j+1]){
                      nextP = j+1;
                      p[j] = nextP;
                  }
                  else{
                      while(temperatures[nextP]<=temperatures[j]){
                          nextP = p[nextP];
                          if(nextP == p[nextP]&&temperatures[nextP]<=temperatures[j]){
                              p[j] = j;
                              break;
                          }
                      }
                      if(temperatures[nextP]>temperatures[j]){
                          p[j] = nextP;
                      }
                  }
              }

          }
          for(int i = 0;i<p.size();i++){
              res[i] = p[i] - i;
          }
          return res;
      }
  };
  ```

        res[T.length - 1] = 0;
        for (int i = T.length - 2; i >= 0; i--) {

                    break;

- 题解的做法
  - 法二！！（**单调栈**）
    - 代码：
      ```cpp
      class Solution {
      public:
          vector<int> dailyTemperatures(vector<int>& temperatures) {
              int n = temperatures.size();
              vector<int> ans(n);
              stack<int> s;
              for (int i = 0; i < n; ++i) {
                  while (!s.empty() && temperatures[i] > temperatures[s.top()]) {
                      int previousIndex = s.top();
                      ans[previousIndex] = i - previousIndex;
                      s.pop();
                  }
                  s.push(i);
              }
              return ans;
          }
      };
      ```
    - 解析：
      维护一个单调递减的栈。记录下标。
      初始时，直接把下标入栈。
      如果当前下标对应的温度大于栈顶对应的温度
        弹出，将其对应下一个更高温度日记为当前下标
        直到栈为空或者栈顶对应温度更高。
        把当前下标入栈。
      因为ans初始都是零，所以对最后一个下标和最后也没有出栈的可以不操作。
      这种方法存储下标，把能处理的处理了，不能的留在栈中，等待后续来的下标。
