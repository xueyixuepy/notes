# 记录
- 题目：
  给定一个只包括 '('，')'，'{'，'}'，'['，']' 的字符串 s ，判断字符串是否有效。
  有效字符串需满足：
  左括号必须用相同类型的右括号闭合。
  左括号必须以正确的顺序闭合。
  每个右括号都有一个对应的相同类型的左括号。
- 示例：
  示例 1：
  输入：s = "()"
  输出：true
  示例 2：
  输入：s = "()[]{}"
  输出：true
  示例 3：
  输入：s = "(]"
  输出：false
- 思路：
  没什么好说的，常见题。
  然而我一直出错误。
  ==注意在循环里出现空是return false；循环之后是空才是trues==
  ==然后是右括号不匹配栈顶也要返回false==
  还有map不知道什么毛病一直报错。
- 代码：
  ```cpp
  class Solution {
  public:
      bool isValid(string s) {
          stack<char> s1;
          map<char, char> m = {{'(', ')'}, {'[', ']'}, {'{', '}'}};
          for(char c:s){
              if(c == '('||c == '[' || c == '{'){
                  s1.push(c);
              }
              else{
                  if(s1.empty()){
                      return false;
                  }
                  else{

                      if(m[s1.top()] == c) s1.pop();
                      else return false;
                  }
              }
          }

          return s1.empty();
      }
  };
  ```
