# 记录
- 题目
  设计一个支持 push ，pop ，top 操作，并能在常数时间内检索到最小元素的栈。
  实现 MinStack 类:
  MinStack() 初始化堆栈对象。
  void push(int value) 将元素 value 推入堆栈。
  void pop() 删除堆栈顶部的元素。
  int top() 获取堆栈顶部的元素。
  int getMin() 获取堆栈中的最小元素。
- 原题：
- 思路：
  毫无疑问是用一个vector来做实际存储，本来打算用双指针，但是其实vector自带pop_back()成员函数来去掉尾部且首位指针是0，所有就不用了。
  难点在于怎么快速地去记录最小值。
  这里我想到了很早以前一题，什么从后往前杀，杀完坐下。
  这里而外维护一个`vector<int> s`，首次push时直接加入value，后续情况只有当value<=尾部值时才加入。核心在于记录==最近最小值==
  只有当pop操作删掉了最近最小值时，才需要对s进行操作,删去了比最近最小值大且来的比他晚的,无关紧要.
  至于为什么要记录等于的,因为删除判断是等于.没法分辨位置.
- 代码:
  ```cpp
  class MinStack {
  public:
      int right;
      int left;
      vector<int> vals;
      vector<int> s;
      MinStack() {
          left = 0;
          right = 0;
      }
      void push(int value) {
          vals.emplace_back(value);
          if(s.size() == 0){
              s.emplace_back(value);
          }
          else{
              if(s.back()>=value){
                  s.emplace_back(value);
              }     
          }
          right ++;
      }
      
      void pop() {
          if(s.back() == vals.back()){
              s.pop_back();
          }
          vals.pop_back();
          right--;                                                                                                                              
      }
      
      int top() {
          return vals.back();
      }
      
      int getMin() {
          return s.back();
      }
  };

  /**
  * Your MinStack object will be instantiated and called as such:
  * MinStack* obj = new MinStack();
  * obj->push(value);
  * obj->pop();
  * int param_3 = obj->top();
  * int param_4 = obj->getMin();
  */
  ```
- 结果
  时间27,空间8.
- 题解的思路:
  使用辅助栈,记录当前栈情况下的最小值,和原栈同步pop和push
  代码:
  ```cpp
  class MinStack {
      stack<int> x_stack;
      stack<int> min_stack;
  public:
      MinStack() {
          min_stack.push(INT_MAX);
      }
      
      void push(int x) {
          x_stack.push(x);
          min_stack.push(min(min_stack.top(), x));
      }
      
      void pop() {
          x_stack.pop();
          min_stack.pop();
      }
      
      int top() {
          return x_stack.top();
      }
      
      int getMin() {
          return min_stack.top();
      }
  };
  ```
- 他人的做法:
  这是一个不使用额外空间的方法.
  先看代码:
  ```python
  class MinStack:
    def __init__(self):
        """
        initialize your data structure here.
        """
        self.stack = []
        self.min_value = -1

    def push(self, x: int) -> None:
        if not self.stack:
            self.stack.append(0)
            self.min_value = x
        else:
            diff = x-self.min_value
            self.stack.append(diff)
            self.min_value = self.min_value if diff > 0 else x

    def pop(self) -> None:
        if self.stack:
            diff = self.stack.pop()
            if diff < 0:
                top = self.min_value
                self.min_value = top - diff
            else:
                top = self.min_value + diff
            return top

    def top(self) -> int:
        return self.min_value if self.stack[-1] < 0 else self.stack[-1] + self.min_value

    def getMin(self) -> int:
        return self.min_value if self.stack else -1
  ```
  核心思想就是记录当前栈的最小值,存储当前val - 当前最小值,而不直接存储val值.
  如果x-self.min_value <,说明当前值比当前栈的最小值还小,更新最小值.
  返回top时,则只需要返回diff+当前最小值即可.但是如果是更新了最小值的那个位置,应该是diff+上一个最小值.没有记录它所以直接返回当前最小值.
  pop的时候,如果发现diff<0,说明这个位置删去时最小值要变,当前最小值 = diff + 上一个最小值.所以最小值就是当前最小值-diff.
