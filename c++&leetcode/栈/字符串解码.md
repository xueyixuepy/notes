# 记录
- 题目：
  给定一个经过编码的字符串，返回它解码后的字符串。
  编码规则为: k[encoded_string]，表示其中方括号内部的 encoded_string 正好重复 k 次。注意 k 保证为正整数。
  你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。
  此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 k ，例如不会出现像 3a 或 2[4] 的输入。
  测试用例保证输出的长度不会超过 105。
- 示例
  示例 1：
  输入：s = "3[a]2[bc]"
  输出："aaabcbc"
  示例 2：
  输入：s = "3[a2[c]]"//**嵌套！！**
  输出："accaccacc"
  示例 3：
  输入：s = "2[abc]3[cd]ef"
  输出："abcabccdcdcdef"
- 思路：
  毫无疑问使用栈，但是该怎么处理呢？
  先把字符一个个压入栈，
  我想的是记录`'['`与`']'`的位置,但是如果是`2[adb3[acd]]`这种情况,最多只能记录到最近的一个的位置.
  不对,也许能再用一个栈记录?
  算了,总之我就只判断有没有遇到`']'`,遇到了之后就开始弹出了,然后把计算得到的结果再压回栈里面,这样就可以处理嵌套.
- 代码:
  ```cpp
  class Solution {
  public:
      string decodeString(string s) {
          string res;
          stack<char> tool;
          string tem;
          string ks;
          string ss;
          int k = 0;
          for(int i = 0; i<s.size();i++){
              tool.push(s[i]);
              if(s[i] == ']'){
                  tool.pop();
                  while(tool.top()!='['){
                      ss = tool.top() + ss;
                      tool.pop();
                  }
                  tool.pop();
                  while(!tool.empty()&&'0'<=tool.top()&&tool.top()<='9'){
                      ks = tool.top()+ks;
                      tool.pop();
                  }
                  k = sToInt(ks);
                  for(int j = 0;j<k;j++){
                      for(char c:ss){
                          tool.push(c);
                      }
                  }
                  ss.clear();
                  ks.clear();
              }
          }
          while(!tool.empty()){
              res = tool.top() + res;
              tool.pop();
          }
          return res;
      }
      int sToInt(string s){
          int num = 0;
          for(char c:s){
              num*=10;
              num+=int(c-'0');
          }
          return num;

      }
  };
  ```

- 题解的做法
  - 法一
    和我的差不多,只是它是存string类型的栈
    代码:
    ```
    class Solution {
    public:
        string getDigits(string &s, size_t &ptr) {
            string ret = "";
            while (isdigit(s[ptr])) {
                ret.push_back(s[ptr++]);
            }
            return ret;
        }

        string getString(vector <string> &v) {
            string ret;
            for (const auto &s: v) {
                ret += s;
            }
            return ret;
        }

        string decodeString(string s) {
            vector <string> stk;
            size_t ptr = 0;

            while (ptr < s.size()) {
                char cur = s[ptr];
                if (isdigit(cur)) {
                    // 获取一个数字并进栈
                    string digits = getDigits(s, ptr);
                    stk.push_back(digits);
                } else if (isalpha(cur) || cur == '[') {
                    // 获取一个字母并进栈
                    stk.push_back(string(1, s[ptr++])); 
                } else {
                    ++ptr;
                    vector <string> sub;
                    while (stk.back() != "[") {
                        sub.push_back(stk.back());
                        stk.pop_back();
                    }
                    reverse(sub.begin(), sub.end());
                    // 左括号出栈
                    stk.pop_back();
                    // 此时栈顶为当前 sub 对应的字符串应该出现的次数
                    int repTime = stoi(stk.back()); 
                    stk.pop_back();
                    string t, o = getString(sub);
                    // 构造字符串
                    while (repTime--) t += o; 
                    // 将构造好的字符串入栈
                    stk.push_back(t);
                }
            }

            return getString(stk);
        }
    };
    ```
    解析:
    它在遇到数字时,继续前进,顺便获取到数字组成的字符串,放入栈中备用.
    一般情况就直接单字符入栈.
    然后遇到`'['`到`']'`,遇到`]`则返回到`'['`,也是做成字符串(用了reverse反转),数字出栈,数字转为int然后字符串重复叠加,再压入栈.
  - 法二
    用的是递归,我还想着如果k[stirng]这种类型嵌套的话还好递归,但是因为可能会跟些孤立的字符串所以不好弄.
    其实也可以.
    分情况就好,如果当前没遇到数字,就正常记录字符,然后返回ret + 递归函数就好.
    非那种形式的字符串会逐个叠加,直到遇到数字,函数执行另一种做法.
    - 代码:
    ```cpp
    class Solution {
    public:
        string src; 
        size_t ptr;

        int getDigits() {
            int ret = 0;
            while (ptr < src.size() && isdigit(src[ptr])) {
                ret = ret * 10 + src[ptr++] - '0';
            }
            return ret;
        }

        string getString() {
            if (ptr == src.size() || src[ptr] == ']') {
                // String -> EPS
                return "";
            }

            char cur = src[ptr]; int repTime = 1;
            string ret;

            if (isdigit(cur)) {
                // String -> Digits [ String ] String
                // 解析 Digits
                repTime = getDigits(); 
                // 过滤左括号
                ++ptr;
                // 解析 String
                string str = getString(); 
                // 过滤右括号
                ++ptr;
                // 构造字符串
                while (repTime--) ret += str; 
            } else if (isalpha(cur)) {
                // String -> Char String
                // 解析 Char
                ret = string(1, src[ptr++]);
            }
            
            return ret + getString();
        }

        string decodeString(string s) {
            src = s;
            ptr = 0;
            return getString();
        }
    };
    ```
