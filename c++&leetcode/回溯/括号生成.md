# 记录
- 题目:
  数字 n 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 有效的 括号组合
- 示例:
  示例 1：
  `输入：n = 3`
  `输出：["((()))","(()())","(())()","()(())","()()()"]`
  示例 2：
  `输入：n = 1`
  `输出：["()"]`
- 思路:
  依旧递归,依旧回溯,我悟了!
  遍历候选解:
  一般情况放入'('.
  '('无效`即返回了`则放入')'
  去掉无效解:
  '('或者')'数量超了.
  string大小等于2n但是不是有效组合,是则记录,都返回.
  这个做法判断函数很重要.
  我一开始写的判断函数很烂,超时了,于是用了豆包给的,成功了
- 代码:
  ```cpp
  class Solution {
  public:
      vector<string> con;
      string tem;
      int left_num= 0;
      int right_num= 0;
      vector<string> generateParenthesis(int n) {
          tool(n);
          return con;
      }
      void tool(int n){
          if(left_num>n) return;
          if(right_num>n) return;
          if(tem.size() == n*2){
              if(judge(tem)) con.emplace_back(tem);
              return;
          }
          tem+='(';
          left_num++;
          tool(n);
          tem.pop_back();
          left_num--;
          tem+=')';
          right_num++;
          tool(n);
          tem.pop_back();
          right_num--;
      }

      bool judge(string kh) {
          stack<char> st;
          for(auto c : kh){
              if(c == '('){
                  st.push(c);
              }else{
                  if(st.empty()) return false;
                  st.pop();
              }
          }
          return st.empty();
      }

  };
  ```
- 结果:
  时间5,空间5
- 新知识(栈解法判断括号组合是否有效)
  ```cpp
  bool judge(string kh) {
      stack<char> st;
      for(auto c : kh){
          if(c == '('){
              st.push(c);
          }else{
              if(st.empty()) return false;
              st.pop();
          }
      }
      return st.empty();
  }
  ```
  - 解析:
    记录左括号,遇到右括号则去掉最近的一个左括号.
    比如()(())->(())->()`删掉了里面那个`->空
    相当于去掉最小合法括号,然后再判断.
  - 复杂度
    O(N)
- 题解的思路
  其中一个就是像我那样的暴力法
  - 法2
    代码:
    ```cpp
    class Solution {
        void backtrack(vector<string>& ans, string& cur, int open, int close, int n) {
            if (cur.size() == n * 2) {
                ans.push_back(cur);
                return;
            }
            if (open < n) {
                cur.push_back('(');
                backtrack(ans, cur, open + 1, close, n);
                cur.pop_back();
            }
            if (close < open) {
                cur.push_back(')');
                backtrack(ans, cur, open, close + 1, n);
                cur.pop_back();
            }
        }
    public:
        vector<string> generateParenthesis(int n) {
            vector<string> result;
            string current;
            backtrack(result, current, 0, 0, n);
            return result;
        }
    };
    ```
    事实上,判断是否有效括号,其实就是从左往右数,记录左括号和右括号数量,右括号一直小于左括号数量且数完后数量相等.
    于是就变成左括号数量小于n则添加左括号`加了之后就等于n了`,右括号数量小于左括号则添加右括号.
    要去除的只有string长度==2n的.
