# 记录
- 题目:
  给你一个字符串 s，请你将 s 分割成一些 子串，使每个子串都是 回文串 。返回 s 所有可能的分割方案
- 示例:
  示例 1：
  `输入：s = "aab"`
  `输出：[["a","a","b"],["aa","b"]]`
  示例 2：
  `输入：s = "a"`
  `输出：[["a"]]`
- 思路
  依旧递归,依旧回溯.
  难点在于怎么去遍历所有可能解.
  - 我一开始想的是记录分割位置,递归时加一,但发现其实传递的字符串分割位置应该从头开始,与父函数无关,所以应该使用for循环.
    仅当左边是回文串时执行,记录分割出来的左边的,递归分割出来的右边的.
    这样子,记录的一定都是回文串.
    无效的情况只有当递归收到的字符串为空时,且此时分割完毕,得到了分割回文字符串列表.回溯,看看其他情况.

  判断是不是回文:
  - 我一开始想的是像"括号生成"那题一样,用栈,然后看看栈顶元素和当前遍历到的字符是不是一样,一样则删除,最后看看是否栈为空.
    然而,对于abbacca这种情况会判断错
  - 于是使用双指针,见代码
- 代码:
  ```cpp
  class Solution {
  public:
      vector<vector<string>> res;
      vector<string> vs;

      vector<vector<string>> partition(string s) {
          tool(s);
          return res;
      }
      void tool(string s){
          if(s.size()==0){
              res.emplace_back(vs);
              return;
          }
          for(int cur = 1;cur<=s.size();cur++){
              string str_left = s.substr(0,cur);
              if(judge(str_left)){
                  vs.emplace_back(str_left);
                  string str_right = s.substr(cur);
                  tool(str_right);
                  vs.pop_back();

              }
          }
      }
      bool judge(string s){
          int i,j;
          for(i = 0,j = s.size()-1;i<=j;i++,j--){
              if(s[i]!=s[j]) return false;
          }
          return true;
      }
  };
  ```

- 题解的做法
  - 和我的差不多,但是判断是否回文用了预处理,同时dfs函数用了i来判断边界,而不是传递分割结果.
    ```cpp
    class Solution {
    private:
        vector<vector<int>> f;
        vector<vector<string>> ret;
        vector<string> ans;
        int n;

    public:
        void dfs(const string& s, int i) {
            if (i == n) {
                ret.push_back(ans);
                return;
            }
            for (int j = i; j < n; ++j) {
                if (f[i][j]) {
                    ans.push_back(s.substr(i, j - i + 1));
                    dfs(s, j + 1);
                    ans.pop_back();
                }
            }
        }

        vector<vector<string>> partition(string s) {
            n = s.size();
            f.assign(n, vector<int>(n, true));

            for (int i = n - 1; i >= 0; --i) {
                for (int j = i + 1; j < n; ++j) {
                    f[i][j] = (s[i] == s[j]) && f[i + 1][j - 1];
                }
            }

            dfs(s, 0);
            return ret;
        }
    };
    ```
    时间复杂度O(n*$2^n$)
    空间复杂度O($n^2$)
