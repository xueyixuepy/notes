# 记录
- 题目：
  给你一个 无重复元素 的整数数组 candidates 和一个目标整数 target ，找出 candidates 中可以使数字和为目标数 target 的 所有 不同组合 ，并以列表形式返回。你可以按 任意顺序 返回这些组合。
  candidates 中的 同一个 数字可以 无限制重复被选取 。如果至少一个数字的被选数量不同，则两种组合是不同的。 
  对于给定的输入，保证和为 target 的不同组合数少于 150 个。
- 示例
  示例 1：
  `输入：candidates = [2,3,6,7], target = 7`
  `输出：[[2,2,3],[7]]`
  解释：
  2 和 3 可以形成一组候选，2 + 2 + 3 = 7 。注意 2 可以使用多次。
  7 也是一个候选， 7 = 7 。
  仅有这两种组合。
  示例 2：
  `输入: candidates = [2,3,5], target = 8`
  `输出: [[2,2,2,2],[2,3,3],[3,5]]`
- 思路：
  依旧递归，依旧回溯，我的脑子里出现了这样一幅画面：
  对于`输入：candidates = [2,3,6,7], target = 7`，递归顺序是
  ```
  2
  22
  222
  2222
  222//回溯
  2223
  222//回溯
  2225
  222//回溯
  22//回溯
  ......
  ```
  为渐渐好像明白回溯是什么道理了。
  舍去无效的，于是总和大于target要返回，等于时要记录并返回（因为记录了所以也无效），访问越界了要返回。
  然后要遍历所有候选解。这就要考虑回溯之后要做什么：
  - 一般情况，还可以选用当前值，则继续选用当前值。
  - 如果当前值也不能选了，访问下一个位置。这只需要在回溯后面加上一个递归即可。如果下一值无法使用，这个语句相当于无效。
  
  这和子集那题都是先确定前缀,然后组合遍历后续所有可能
- 代码：
  ```cpp
  class Solution {
  public:
      vector<vector<int>> con;
      vector<int> tem;
      int sum = 0;
      int first = 0;
      vector<vector<int>> combinationSum(vector<int>& candidates, int target) {
          tool(candidates,target,0);
          return con;
      }
      void tool(vector<int>& candidates, int target,int cur){ 
          if(cur == candidates.size()) return;
          if(sum == target){
              con.emplace_back(tem);
              return;
          }      
          else if(sum>target){
              return;
          }
          sum+=candidates[cur];
          tem.emplace_back(candidates[cur]);
          tool(candidates,target,cur);
          sum-=candidates[cur];
          tem.pop_back();
          tool(candidates,target,cur+1);

      }
  };
  ```
