# 记录
- 题目：
  在给定的 m x n 网格 grid 中，每个单元格可以有以下三个值之一：
  值 0 代表空单元格；
  值 1 代表新鲜橘子；
  值 2 代表腐烂的橘子。
  每分钟，腐烂的橘子 周围 4 个方向上相邻 的新鲜橘子都会腐烂。
  返回 直到单元格中没有新鲜橘子为止所必须经过的最小分钟数。如果不可能，返回 -1 。
- 思路：
  - 一开始错误的思路：
    看到这题想到了“岛屿数量”那题用到的递归感染（深度优先搜索），但是其实是不能用的，因为腐烂传递的顺序变了。
  - 新的思路：
    改成广度优先搜索，使用队列，记录横纵坐标与标记，先遍历一遍，找出所有腐烂的橘子，加入队列，标记为0，表示第0min腐烂。
    然后开始在队列中操作，取出队列前面的元素，感染周围，被感染的标记为它的标记加1，然后加入队列。
    如此重复，记住最后一个被感染的橘子的标记。
    此外还要去再遍历一遍，因为可能有橘子永远未被感染，此时返回-1。
- 代码：
  ```cpp
  class Solution {
  public:

      int orangesRotting(vector<vector<int>>& grid) {
          int minute = 0;
          queue<vector<int>> q;
          vector<int> ij;
          for(int i =0;i<grid.size();i++){
              for(int j = 0; j< grid[i].size();j++){
                  if(grid[i][j]==2){
                      q.push({i,j,0});
                  }
              }
          }
          while(q.size()){
              ij = q.front();
              if(ij[0]-1>=0&&grid[ij[0]-1][ij[1]] == 1){
                  grid[ij[0]-1][ij[1]] = 2;
                  q.push({ij[0]-1,ij[1],ij[2]+1});
              }
              if(ij[1]-1>=0&&grid[ij[0]][ij[1]-1] == 1){
                  grid[ij[0]][ij[1]-1] = 2;
                  q.push({ij[0],ij[1]-1,ij[2]+1});
              } 
              if(ij[0]+1<grid.size()&&grid[ij[0]+1][ij[1]] == 1){
                  grid[ij[0]+1][ij[1]] = 2;
                  q.push({ij[0]+1,ij[1],ij[2]+1});
              }
              if(ij[1]+1<grid[ij[0]].size()&&grid[ij[0]][ij[1]+1] == 1){
                  grid[ij[0]][ij[1]+1] = 2;
                  q.push({ij[0],ij[1]+1,ij[2]+1});
              }
              minute = ij[2]; 
              q.pop();
          }
          for(int i =0;i<grid.size();i++){
              for(int j = 0; j< grid[i].size();j++){
                  if(grid[i][j]==1){
                      minute = -1;
                  }
              }
          }
          return minute;
      }
  };
  ``` 
- 结果：
  时间18，空间10，好烂呀，而且改bug改了好久。
- 他人的做法：
  思路是一样的，但是代码写的就是比我好，气人。
  ```cpp
  class Solution {
  public:
      using PII=pair<int,int>;

      static constexpr int dx[4]={1,0,-1,0},dy[4]={0,1,0,-1};

      int orangesRotting(vector<vector<int>>& g) 
      {
          int n=g.size(),m=g[0].size(),sum=0;
          queue<PII> q;
          for(int i=0;i<n;i++)
          {
              for(int j=0;j<m;j++)
              {
                  if(g[i][j]==1)  ++sum;
                  else if(g[i][j]==2)  q.emplace(i,j);
              }
          }
          int level=0;
          for(;q.size()&&sum>0;++level)
          {
              for(int size=q.size();size;size--)
              {
                  auto [x,y]=q.front();
                  q.pop();
                  for(int i=0;i<4;i++)
                  {
                      int a=x+dx[i],b=y+dy[i];
                      if(a>=0&&a<n&&b>=0&&b<m&&g[a][b]==1)
                      {
                          q.emplace(a,b);
                          g[a][b]=2,--sum;
                      }
                  }
              }
          }
          return sum==0?level:-1;
      }
  };
  ```
  - 解析：
    第一次遍历的时候记录新鲜橘子数量，腐烂的时候--来判断最后也没有新鲜橘子。
    两层循环，里层永远只恰好处理新加的元素。记录外层循环次数。（其实这个我也想过）
  - 结果：
    时间100%，空间80%
