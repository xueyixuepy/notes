# 记录
- 题目：
  你这个学期必须选修 numCourses 门课程，记为 0 到 numCourses - 1 。
  在选修某些课程之前需要一些先修课程。 先修课程按数组 prerequisites 给出，其中 prerequisites[i] = [ai, bi] ，表示如果要学习课程 ai 则 必须 先学习课程  bi 。
  例如，先修课程对 [0, 1] 表示：想要学习课程 0 ，你需要先完成课程 1 。
  请你判断是否可能完成所有课程的学习？如果可以，返回 true ；否则，返回 false 。
- 注释：
  所有课程是0，1，2一直到numCourses - 1这些个数表示
- 思路：
  图论忘光光了，问了ai，可以使用Kahn算法（入度法），采用的是BFS
  大体方法是先遍历一遍，记录每个点的入度。然后找出入度为0的点加入队列，然后对队列操作，弹出首位，然后将它指向的所有点入度-1，即切断它与其他点的连接。如果这个过程产生了新的入度为0的点，则将其加入队列。
  这样一来，队列中出现的所有点都将是独立的，如果说图中不存在环，那么独立的点的个数和图中点个数相同。
  本题等价于判断有向图中是否有环。
  其实用出度也可以，不过用入度更加有意义，表示一个个学。
- 代码：
  ```cpp
  class Solution {
  public:
      bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
          vector<int> v(numCourses,0);
          queue<int> q;
          int cou = 0;
          int tem;
          for(int i = 0;i<prerequisites.size();i++){
              v[prerequisites[i][0]]++;
          }
          for(int i = 0;i<v.size();i++){
              if(v[i] == 0) q.push(i);
          }
          while(q.size()){
              tem = q.front();
              for(int i = 0;i<prerequisites.size();i++){
                  if(prerequisites[i][1] == tem){
                      v[prerequisites[i][0]]--;
                      if(v[prerequisites[i][0]] == 0){
                          q.push(prerequisites[i][0]);
                      }
                  }
              }
              q.pop();
              cou++;
          }
          if(cou == numCourses){
              return true;
          }
          else{
              return false;
          }
      }
  };
  ```
- 结果：
  时间5%，空间99%。
- 题解的做法:
  其实提示里第一个是说可以dfs的.
  代码:
  ```cpp
  class Solution {
  private:
      vector<vector<int>> edges;
      vector<int> visited;
      bool valid = true;

  public:
      void dfs(int u) {
          visited[u] = 1;
          for (int v: edges[u]) {
              if (visited[v] == 0) {
                  dfs(v);
                  if (!valid) {
                      return;
                  }
              }
              else if (visited[v] == 1) {
                  valid = false;
                  return;
              }
          }
          visited[u] = 2;
      }

      bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
          edges.resize(numCourses);
          visited.resize(numCourses);
          for (const auto& info: prerequisites) {
              edges[info[1]].push_back(info[0]);
          }
          for (int i = 0; i < numCourses && valid; ++i) {
              if (!visited[i]) {
                  dfs(i);
              }
          }
          return valid;
      }
  };
  ```
  解析:
  - 先记录每个课的先修列表,外加准备一个`vector<int> visited;`来记录状态.
    使用深度优先搜索,对每一门课程,标记为搜索中1,如果先修列表不为空,去dfs先修列表中的元素,如果该元素处于未搜索0的话.搜索完先修列表后标记为搜索完2.
    毫无疑问,在返回时没有环的子图,都是会一个个标记为2.而有环的子图,则是会在查找过程中找到搜索中状态的课程,此时直接全局修改vaild为false.

  复杂度:
  - 复杂度分析
    时间复杂度: O(n+m)，其中 n 为课程数，m 为先修课程的要求数。这其实就是对图进行深度优先搜索的时间复杂度。
    空间复杂度: O(n+m)。题目中是以列表形式给出的先修课程关系，为了对图进行深度优先搜索，我们需要存储成邻接表的形式，空间复杂度为 O(n+m)。在深度优先搜索的过程中，我们需要最多 O(n) 的栈空间（递归）进行深度优先搜索，因此总空间复杂度为 O(n+m)。
- 仿造题解的算法优化自己的bfs算法：
  代码：
  ```cpp
  class Solution {
  public:
      bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
          vector<int> v(numCourses,0);
          vector<vector<int>> edges(numCourses); 
          queue<int> q;
          int cou = 0;
          int tem;
          for(int i = 0;i<prerequisites.size();i++){
              edges[prerequisites[i][1]].emplace_back(prerequisites[i][0]);
              v[prerequisites[i][0]]++;
          }
          for(int i = 0;i<v.size();i++){
              if(v[i] == 0) q.push(i);
          }
          while(q.size()){
              tem = q.front();
              for(int i = 0;i<edges[tem].size();i++){
                  v[edges[tem][i]]--;
                  if(v[edges[tem][i]] == 0) q.push(edges[tem][i]);
              }
              q.pop();
              cou++;
          }
          if(cou == numCourses){
              return true;
          }
          else{
              return false;
          }
      }
  };
  ```
  主要修改了入度的遍历部分，制作了课程的出度表。遍历出度表修改入度。
  - 结果：
  时间50，空间50.和题解的BFS几乎一样。
