- 题目:
  给定一个字符串 s ，请你找出其中不含有重复字符的 最长 子串 的长度。
- 示例:
  示例 1:
  输入: s = "abcabcbb"
  输出: 3 
  解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。
  示例 2:
  输入: s = "bbbbb"
  输出: 1
  解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。
  示例 3:
  输入: s = "pwwkew"
  输出: 3
  解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
  请注意，你的答案必须是 子串 的长度，"pwke" 是一个子序列，不是子串。
---
- 思路:
  双指针滑动窗口,利用map记录窗口内元素的位置,移动右边界,更新左边界
- 代码:
  ```cpp
  class Solution {
  public:
      int lengthOfLongestSubstring(string s) {
          int left = 0;
          int right = 0;
          map<char,int> m;
          int maxLength = 0;
          for(;right<s.size();right++){
              if(m.count(s[right])&&m[s[right]]>=left&&m[s[right]]<=right){
                  left = m[s[right]] + 1;
                  m[s[right]] = right;
                  if(right < left) right = left;
              }
              else{
                  m[s[right]] = right;
              }
              maxLength = max(maxLength,right-left+1);
          }
          return maxLength;
      }
  };
  ```
- 结果:
  时间45,空间42

**题解的做法**
- 思路
  差不多,也是用map记录.
  只不过,它是判断是否存在键,如果发生冲突,则左指针不断移动,直到冲突消失
- 代码:
  ```cpp
  class Solution {
  public:
      int lengthOfLongestSubstring(string s) {
          // 哈希集合，记录每个字符是否出现过
          unordered_set<char> occ;
          int n = s.size();
          // 右指针，初始值为 -1，相当于我们在字符串的左边界的左侧，还没有开始移动
          int rk = -1, ans = 0;
          // 枚举左指针的位置，初始值隐性地表示为 -1
          for (int i = 0; i < n; ++i) {
              if (i != 0) {
                  // 左指针向右移动一格，移除一个字符
                  occ.erase(s[i - 1]);
              }
              while (rk + 1 < n && !occ.count(s[rk + 1])) {
                  // 不断地移动右指针
                  occ.insert(s[rk + 1]);
                  ++rk;
              }
              // 第 i 到 rk 个字符是一个极长的无重复字符子串
              ans = max(ans, rk - i + 1);
          }
          return ans;
      }
  };
  ```
