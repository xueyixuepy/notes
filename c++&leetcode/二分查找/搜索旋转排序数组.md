# 记录
- 题目
  整数数组 nums 按升序排列，数组中的值 互不相同 。
  在传递给函数之前，nums 在预先未知的某个下标 k（0 <= k < nums.length）上进行了 向左旋转，使数组变为 `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]（下标 从 0 开始 计数）`。例如， `[0,1,2,4,5,6,7]` 下标 3 上向左旋转后可能变为 `[4,5,6,7,0,1,2]` 。
  给你 旋转后 的数组 nums 和一个整数 target ，如果 nums 中存在这个目标值 target ，则返回它的下标，否则返回 -1 。
  你必须设计一个时间复杂度为 O(log n) 的算法解决此问题。
- 示例：
  示例 1：
  `输入：nums = [4,5,6,7,0,1,2], target = 0`
  `输出：4`
  示例 2：
  `输入：nums = [4,5,6,7,0,1,2], target = 3`
  `输出：-1`
  示例 3：
  `输入：nums = [1], target = 0`
  `输出：-1`
- 思路:
  思路是对的,但是能力是不足的.
  毫无疑问,可以先找到旋转的位置,然后再对关键点左右两边分别进行二分查找.
  如果旋转发生在末尾,则另外考虑,先判断最左值是否<=最右值,是的话说明旋转在末尾(等于判断是否单一元素).直接进行二分查找.
  其他情况,则得先找旋转点.关键就在这里,也得要二分法.
  然而我的愚蠢的大脑始终想不到怎么做,自己试着修改,在大脑里遍历各种情况,还是错的.
  最后还是ai告诉了我怎么找.
  具体情况见代码.
  ==注意:循环条件判断是<,right是变为mid,只判断nums[mid]是否大于nums[right],最后left一定会等于right,循环结束,此时left与right的值就是要的旋转点的下标==
- 代码:
  ```cpp
  class Solution {
  public:
      int search(vector<int>& nums, int target) {
          int left= 0;
          int right= nums.size()-1;
          int mid;
          int z;
          if(nums[left]<=nums[right]){
              return erfen(nums,target,left,right);
          }
          while(left<right){
              mid = (left+right)/2;

              if(nums[mid]>nums[right]){
                left = mid + 1;
              }
              else{
                  right = mid;
              }

          }
          z = left;
          int leftFind = erfen(nums,target,0,z-1);
          int rightFind = erfen(nums,target,z,nums.size()-1);
          return leftFind != -1?leftFind:rightFind;
          
      }
      int erfen(vector<int>& nums, int target,int left,int right){
          int mid;
          while(left<=right){
              mid = (left+right)/2;
              if(nums[mid] == target){
                  return mid;
              }
              if(nums[mid]<target){
                  left = mid + 1;
              }
              if(nums[mid]>target){
                  right = mid - 1;

              }

          }
          return -1;
      }
  };
  ```
