# 记录
- 题目：
  给你一个满足下述两条属性的 m x n 整数矩阵：
  每行中的整数从左到右按非严格递增顺序排列。
  每行的第一个整数大于前一行的最后一个整数。
  给你一个整数 target ，如果 target 在矩阵中，返回 true ；否则，返回 false 。
  你必须编写一个时间复杂度为 O(log(m * n)) 的解决方案。
- 思路：
  毫无疑问就是二分法。
  记录left，mid，right
  把矩阵展开来看。
  注意left和right都是可以被搜索到的，所以right的初始值得是矩阵大小-1.
- 代码：
  ```cpp
  class Solution {
  public:
      bool searchMatrix(vector<vector<int>>& matrix, int target) {
          int left = 0;
          int right = matrix.size()*matrix[0].size()-1;
          int mid ;
          int find;
          int x;
          int y;
          while(left<=right){
              mid = (left+right)/2;
              x = mid/matrix[0].size();
              y = mid%matrix[0].size();
              if(matrix[x][y] == target){
                  return true;
              }
              else if(matrix[x][y]>target){
                  right = mid-1;
              }
              else{
                  left = mid+1;
              }
          }
          return false;
      }
  };
  ```
- 结果:
  没什么好说的,时间100,空间63.

  - 方法1
    代码:
    ```cpp
    class Solution {
    public:
        bool searchMatrix(vector<vector<int>> matrix, int target) {
            auto row = upper_bound(matrix.begin(), matrix.end(), target, [](const int b, const vector<int> &a) {
                return b < a[0];
            });
            if (row == matrix.begin()) {
                return false;
            }
            --row;
            return binary_search(row->begin(), row->end(), target);
        }
    };
    ```
    这个是进行了两次二分查找,因为这个矩阵行列都是递增的,先在第一列二分查找,找到最小的不大于target的,然后在该行进行二分查找
    时间复杂度和我那个一样,莫得区别.都是O(logmn).
