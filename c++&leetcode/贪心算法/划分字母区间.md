- 题目：
  给你一个字符串 s 。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。例如，字符串 "ababcc" 能够被分为 ["abab", "cc"]，但类似 ["aba", "bcc"] 或 ["ab", "ab", "cc"] 的划分是非法的。
  注意，划分结果需要满足：将所有划分结果按顺序连接，得到的字符串仍然是 s 。
  返回一个表示每个字符串片段的长度的列表。
- 示例：
  示例 1：
  输入：s = "ababcbacadefegdehijhklij"
  输出：[9,7,8]
  解释：
  划分结果为 "ababcbaca"、"defegde"、"hijhklij" 。
  每个字母最多出现在一个片段中。
  像 "ababcbacadefegde", "hijhklij" 这样的划分是错误的，因为划分的片段数较少。 
  示例 2：
  输入：s = "eccbbbbdec"
  输出：[10]
- 我的理解
  题目是说，划分的结果中，每个分割出来的字符串不能有相同的字符。
  比如ababcc，因为有两个a，所以一定要划到aba，否则ab，abcc，就出现两个字符串都有a
  b也同理，所以最多只能划为abab，cc
- 思路：
  双指针，一个从后往前，一个从左往后，对于每一个left，遍历字符串最右边到right，right为已经确定要划到的位置。left一直向右，如果right遍历过程中发现和left指向的字符一样，right更新，
  一直到right不更新，left也一直向右，
  left最后会和right相等，说明这是一个最好的分割，记录当前长度，left和right向右移动。
- 代码：
  ```cpp
  class Solution {
  public:
      vector<int> partitionLabels(string s) {
          int left = 0;
          int right = 0;
          int count = 0;
          vector<int> res;
          while(true){
              for(int i = s.size()-1;i>right;i--){
                  if(s[i] == s[left])
                  {
                      right = i;
                      break;
                  }
              }
              count++;
              if(left == right){
                  res.emplace_back(count);
                  count = 0;
                  right++;
              }   
              if(left == s.size()-1){
                  break;
              }
              left++;
          }
          return res;
      }
  };
  ```
- 结果:
  时间5,空间60

- 思路2：
  注意到这题字符只能是小写字母，于是可以准备一个大小为26的vector来存储每个字母第一次出现和最后一次出现的位置。
  最后会得到一系列数组。
  需要合并区间，合并区间的内容去看普通数组文件夹
  合并之后得到的最后的几个区间，也一定是从左往右差一连续的。
  返回合并后的区间的大小即可
- 代码：
  ```cpp
  class Solution {
  public:
      vector<int> partitionLabels(string s) {
          int left = 0;
          int right = 0;
          int count = 0;
          vector<int> res;
          vector<vector<int>> rem(26);
          for(int i = 0;i<s.size();i++){
              if(rem[int(s[i]-'a')].size() == 0){
                  rem[int(s[i]-'a')].emplace_back(i);
                  rem[int(s[i]-'a')].emplace_back(i);
              }
              else{
                  rem[int(s[i]-'a')][1] = i;
              }
          }
          vector<vector<int>> hbdsz;
          hbdsz=hbsz(rem);
          for(int i = 0;i<hbdsz.size();i++){
              res.emplace_back(hbdsz[i][1]-hbdsz[i][0]+1);
          }
          return res;
      }
      vector<vector<int>> hbsz(vector<vector<int>>& nums){
          sort(nums.begin(),nums.end());
          int L;
          int R;
          vector<vector<int>> res;
          // vector<int> tem(2);
          for(int i = 0;i<nums.size();i++){
              if(nums[i].size() == 0){
                  continue;
              }
              L = nums[i][0];
              R = nums[i][1];
              if(res.size() == 0||res.back()[1]<L){
                  // tem[0] = L;
                  // tem[1] = R;
                  res.push_back({L,R});
              }
              else{
                  res.back()[1] = max(res.back()[1],R);
              }
          }
          return res;

      }

  };
  ```
- 结果:
  时间100,空间5

- 题解的做法;
  差不多可以理解为合并区间,不过他是记录每个字母出现的最后位置end
  然后从左向右遍历
  如果当前字符的end>=原来end,则继续遍历,可以合并.
  小于则说明区间不能合并了,记录当前长度,然后start++;
  很妙呀,从左到右天然使得区间是按左边大小升序的
- 代码:
  ```cpp
  class Solution {
  public:
      vector<int> partitionLabels(string s) {
          int last[26];
          int length = s.size();
          for (int i = 0; i < length; i++) {
              last[s[i] - 'a'] = i;
          }
          vector<int> partition;
          int start = 0, end = 0;
          for (int i = 0; i < length; i++) {
              end = max(end, last[s[i] - 'a']);
              if (i == end) {
                  partition.push_back(end - start + 1);
                  start = end + 1;
              }
          }
          return partition;
      }
  };
  ```
