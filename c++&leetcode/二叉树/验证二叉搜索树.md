# 记录
- 题目：
  给你一个二叉树的根节点 root ，判断其是否是一个有效的二叉搜索树。
  有效 二叉搜索树定义如下：
  节点的左子树只包含 严格小于 当前节点的数。
  节点的右子树只包含 严格大于 当前节点的数。
  所有左子树和右子树自身必须也是二叉搜索树。
- 注释：
  注意是所有在左边的都要比自身小，而不仅仅是自己的左子结点比自己小，左子结点的右子树也得比自己小。
  右边一样。
- 思路：
  依旧递归，且操作是在回归的时候进行，要记住三个值，是否是二叉搜索树，当前树的最大值，当前树的最小值。故而返回列表。
- 代码：
  ```cpp
    /**
  * Definition for a binary tree node.
  * struct TreeNode {
  *     int val;
  *     TreeNode *left;
  *     TreeNode *right;
  *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
  *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
  *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
  * };
  */                   
  class Solution {
  public:
      int m1;
      int m2;
      bool isValidBST(TreeNode* root) {
          return tool(root)[0];
      }
      vector<int> tool(TreeNode* root){

          vector<int> v;
          bool judge = true;
          int maxR = root->val;
          int minR = root->val;
          vector<int> v1;
          vector<int> v2;
          if(root->left==nullptr&&root->right==nullptr){
              v.emplace_back(1);
              v.emplace_back(root->val);
              v.emplace_back(root->val);
              return v;
          }
          if(root->left!=nullptr){
              v1 = tool(root->left);
              judge &= (root->val>v1[1])&&v1[0];
              maxR = max(maxR,v1[1]); 
              minR = min(minR,v1[2]);

          }
          if(root->right!=nullptr){
              v2 = tool(root->right);
              judge &= (root->val<v2[2])&&v2[0];
              minR = min(minR,v2[2]);
              maxR = max(maxR,v2[1]); 
          }         
          v.emplace_back(judge);
          v.emplace_back(maxR);
          v.emplace_back(minR);
          return v;
      }
  };
  ```
- 结果：
  依旧是时间空间都很差，个位数。
- 看到评论区有提到中序遍历，好像是这样的，中序遍历是升序呀。于是我自己再做一遍
  - 代码：
    ```cpp
    class Solution {
    public:
        vector<int> con; 
        bool isValidBST(TreeNode* root) {
            this->tool(root);
            if(this->con.size()==1) return true;
            for(int i = 0;i<this->con.size()-1;i++){
                if(this->con[i]>=this->con[i+1]){
                    return false;
                }
            }
            return true;
        }
        void tool(TreeNode* root){
            if(root==nullptr){
                return;
            }
            tool(root->left);
            this->con.emplace_back(root->val);
            tool(root->right);

        }
    };
    ```
  - 中序遍历严格递增
  - 结果：
    时间100%，空间30%
