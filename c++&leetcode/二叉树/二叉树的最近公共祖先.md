# 记录
- 题目：
  给定一个二叉树, 找到该树中两个指定节点的最近公共祖先。
  最近公共祖先的定义为：“对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。”
  树中节点数目在范围 [2, 105] 内。
  -109 <= Node.val <= 109
  所有 Node.val 互不相同 。
  p != q
  p 和 q 均存在于给定的二叉树中。
- 思路：
  依旧递归遍历，另开一个函数，返回int类型，如果当前结点是p或q的一个，则记下，当记录值第一次为2时，说明找到了最近公共祖先。
- 代码：
  ```cpp
  /**
   * Definition for a binary tree node.
   * struct TreeNode {
   *     int val;
   *     TreeNode *left;
   *     TreeNode *right;
   *     TreeNode(int x) : val(x), left(NULL), right(NULL) {}
   * };
   */
  class Solution {
  public:
      TreeNode* Ancestor;
      TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
          tool(root,p,q);
          return this->Ancestor;

      }
      int tool(TreeNode* root, TreeNode* p, TreeNode* q){
          if(root == NULL) return 0;
          int ret = 0;
          if(root == p) ret++;
          if(root == q) ret++;

          ret+=tool(root->left,p,q)+tool(root->right,p,q);
          if(ret == 2)
          {
              this->Ancestor = root;
              ret++;
          }
          return ret;

      }
  };
  ```
- 结果：
  时间25%，空间14%
- 他人的做法
  也是递归，也是返回时操作，非常简洁漂亮。
  代码：
  ```cpp
  class Solution {
  public:
      TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
          if(!root || root==p || root==q) return root;
          TreeNode* L = lowestCommonAncestor(root->left,p,q);
          TreeNode* R = lowestCommonAncestor(root->right,p,q);
          return L&&R ? root : (L ? L : R);
      }
  };
  ```
  解析：
  只在三种情况下返回，是p或q或空结点。
  对于其中一个p或q，递归到了它，会返回它自己，然后到了它的父结点，如果父结点只是一个中继的话，则L&&R是非，仍返回它自己。
  如果L&&R，则表示p和q分别在当前结点的左右子树，当前结点就是最近公共祖先。，返回到了它的夫结点时，L&&R会是非，仍返回那个公共祖先。
  如果是p或q中的一个是公共祖先的情况，则，L&&R会一直是否，此时返回的会是最后的p或q。因为返回会启用
  ```cpp
  if(!root || root==p || root==q) return root;
  ```
  此后一直返回最后的p或q，即公共祖先。
