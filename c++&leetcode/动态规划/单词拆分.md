# 记录
---
- 题目
  给你一个字符串 s 和一个字符串列表 wordDict 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 s 则返回 true。
  注意：不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。
- 示例
  示例 1：
  输入: s = "leetcode", wordDict = ["leet", "code"]
  输出: true
  解释: 返回 true 因为 "leetcode" 可以由 "leet" 和 "code" 拼接成。
  示例 2：
  输入: s = "applepenapple", wordDict = ["apple", "pen"]
  输出: true
  解释: 返回 true 因为 "applepenapple" 可以由 "apple" "pen" "apple" 拼接成。
      注意，你可以重复使用字典中的单词。
  示例 3：
  输入: s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]
  输出: false
---
- 思路:
  老样子,找关系.
  设f(x)为x能被组成
  在其组成中,其第一个前缀为j
  则去掉j,剩下的也一定要能够组成
  f(x) = x在词典中有一个前缀与上去掉该前缀得到的f(x')
  于是我想到了递归,记录当前位置.
  如果找到前缀,移动,看看剩下的是什么情况
  最后如果当前位置成功到了s的后面,说明成功匹配了.
  但是这样会超时.
  考虑到这题是动态规划,需要"记忆"
  记什么呢?记当前位置切割出来的字符串有没有没判断过是否能被组成.
  如果被判断过,就不要再递归一遍
  没有判断过,则递归.
- 代码:
  ```cpp
  class Solution {
  public:
      bool res = false;
      unordered_map<int,bool> m;
      bool wordBreak(string s, vector<string>& wordDict) {
          //f(x) = x可以被拼出
          //假设作为前缀的单词是j
          //j属于wordDict
          //f(x) = true与f(x[j.size():])
          dfs(s,0,wordDict);
          return res;
      }

      void dfs(string& s,int cur,vector<string>& wordDict){
          if(m[cur] == true){
              return;
          }
          m[cur] = true;
          if(cur == s.size()){
              res = true;
              return;
          }
          //遍历词典看有没有匹配的前缀
          for(int i = 0;i<wordDict.size();i++){
              bool isFound = false;
              if(s.size()-cur>=wordDict[i].size()){
                  isFound = true;
                  for(int j = 0;j<wordDict[i].size();j++){
                      if(s[j+cur]!=wordDict[i][j]){
                          isFound = false;
                      }
                  }
              }
              if(isFound&&res==false){
                  dfs(s,cur+wordDict[i].size(),wordDict);
              }
          }
      }
  };
  ```
- 结果:
  时间76,空间78
--- 
- 题解的做法
  f(i)表示字符串s[:i]可以被组成
  记录f(i)
  假设f(i) 是 true,则其一定有个在词典里的后缀
  假设后缀位于[j:i]
  则
  f(i) = f(j)&&if(s[j:i] in dict)
  于是只需要找到一个j满足上述条件即可证明f(i)是true
  因为j的位置不确定,但其肯定在i之前
  所以对于每个f(i)
  遍历0到j
  求f(j)&&if(s[j:i] in dict)
  如果有一个是true,则f(i)是true
- 代码:
  ```cpp
  class Solution {
  public:
      bool wordBreak(string s, vector<string>& wordDict) {
          auto wordDictSet = unordered_set <string> ();
          for (auto word: wordDict) {
              wordDictSet.insert(word);
          }

          auto dp = vector <bool> (s.size() + 1);
          dp[0] = true;
          for (int i = 1; i <= s.size(); ++i) {
              for (int j = 0; j < i; ++j) {
                  if (dp[j] && wordDictSet.find(s.substr(j, i - j)) != wordDictSet.end()) {
                      dp[i] = true;
                      break;
                  }
              }
          }

          return dp[s.size()];
      }
  };
  ```
- 结果
  时间20,空间54
