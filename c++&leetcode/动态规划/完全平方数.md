- 题目：
  给你一个整数 n ，返回 和为 n 的完全平方数的最少数量 。
  完全平方数 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，1、4、9 和 16 都是完全平方数，而 3 和 11 不是。
- 示例
  示例 1：
  输入：n = 12
  输出：3 
  解释：12 = 4 + 4 + 4
  示例 2：
  输入：n = 13
  输出：2
  解释：13 = 4 + 9
---
- 思路：
  完全做不了，想不出来怎么找到关系，12不能拆成9+3，但是13又要拆成9+4

  我是废物

- 题解的做法
  - 法一（动态规划）
    f(i)表示最少需要多少个完全平方数表示i
    这些平方数一定会小于等于\(\sqrt i\)
    假设最小组合中一个数为$j^2$
    那么f(i) = 1 + f(i-$j^2$)
    j是不确定的,但是j小于等于\(\sqrt i\)
    于是得到状态转移方程:
    \(f[i]=1+\min_{j=1}^{\lfloor\sqrt i\rfloor} f[i-j^2]\)
    另外,规定f(0) = 0;
  - 代码:
    ```cpp
    class Solution {
    public:
        int numSquares(int n) {
            vector<int> f(n + 1);//f(0) == 0,不去动他
            for (int i = 1; i <= n; i++) {
                int minn = INT_MAX;
                for (int j = 1; j * j <= i; j++) {
                    minn = min(minn, f[i - j * j]);
                }
                f[i] = minn + 1;
            }
            return f[n];
        }
    };
    ```
