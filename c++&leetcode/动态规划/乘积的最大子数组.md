- 题目：
  给你一个整数数组 nums ，请你找出数组中乘积最大的非空连续 子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。
  测试用例的答案是一个 32-位 整数。
  请注意，一个只包含一个元素的数组的乘积是这个元素的值。
- 示例：
  示例 1:
  输入: nums = [2,3,-2,4]
  输出: 6
  解释: 子数组 [2,3] 有最大乘积 6。
  示例 2:
  输入: nums = [-2,0,-1]
  输出: 0
  解释: 结果不能为 2, 因为 [-2,-1] 不是子数组。
---
- 思路：
  见代码注释
- 代码：
  ```cpp
  class Solution {
  public:
      int maxProduct(vector<int>& nums) {
          //f(n) = 以n为子数组末尾时的最大乘积
          //f(n) = max(f(n-1)*nums[n],nums[n])
          //这题的坑在于，如果当前值是负数，则应该乘以上一个最小值
          //一个不行，用两个
          //g(n) = 以n为末尾的最小乘积
          //f(n) = max(f(n-1)*nums[n],nums[n],g(n-1)*nums[n]);
          vector<int> rem(nums.size());
          vector<int> remMin(nums.size());
          int res = INT_MIN;
          for(int i = 0;i<nums.size();i++){
              if(i==0){
                  rem[i] = nums[i];
                  remMin[i] = nums[i];
              }
              else{
                  rem[i] = max(rem[i-1]*nums[i],nums[i]);
                  rem[i] = max(remMin[i-1]*nums[i],rem[i]);
                  remMin[i] = min(remMin[i-1]*nums[i],nums[i]);
                  remMin[i] = min(rem[i-1]*nums[i],remMin[i]);
              }
              res = max(res,rem[i]);
          }
          return res;

      }
  };
  ```
