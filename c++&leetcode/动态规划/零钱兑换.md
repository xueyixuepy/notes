# 记录

- 题目
  给你一个整数数组 coins ，表示不同面额的硬币；以及一个整数 amount，表示总金额。
  计算并返回可以凑成总金额所需的 最少 的硬币个数。如果没有任何一种硬币组合能组成总金额，返回 -1 。
  你可以认为每种硬币的数量是无限的。
- 示例：
  示例 1：
  输入：coins = [1, 2, 5], amount = 11
  输出：3 
  解释：11 = 5 + 5 + 1
  示例 2：
  输入：coins = [2], amount = 3
  输出：-1
  示例 3：
  输入：coins = [1], amount = 0
  输出：0
---
- 思路：
  和完全平方数那题思路一样，见解析，
  就是还要处理不存在组合的情况的情况
- 代码：
  ```cpp
    class Solution {
  public:
      int coinChange(vector<int>& coins, int amount) {
          //f(x) = 凑成金额x所需的最少硬币数
          //假设其中一枚硬币为j
          //则f(x) = 1+f(x-j)
          //j一定在coins中
          //f(x) = 1 + min(f(x-j),j属于coins)
          //     = -1,没这个组合       
          //f(0) = 0
          bool exist = false;
          vector<int> rem(amount+1);
          int minFxj = INT_MAX;
          for(int i = 1;i<=amount;i++){
              for(int j : coins){
                  if(i-j>=0&&rem[i-j]!=-1){
                      minFxj = min(minFxj,rem[i-j]);
                      exist = true;
                  }
              }   
              if(exist){
                  rem[i] = 1+minFxj;
              }
              else{
                  rem[i] = -1;
              }
              exist = false;
              minFxj = INT_MAX;
          }
          return rem[amount];
      }
  };
  ```
- 结果：
  时间24，空间20

- 题解的思路
  一样的
  代码：
  ```cpp
  class Solution {
  public:
      int coinChange(vector<int>& coins, int amount) {
          int Max = amount + 1;
          vector<int> dp(amount + 1, Max);
          dp[0] = 0;
          for (int i = 1; i <= amount; ++i) {
              for (int j = 0; j < (int)coins.size(); ++j) {
                  if (coins[j] <= i) {
                      dp[i] = min(dp[i], dp[i - coins[j]] + 1);
                  }
              }
          }
          return dp[amount] > amount ? -1 : dp[amount];
      }
  };
  ```
  如果dp[i-coins[j]]存在，则dp[i]会是一个比MAX_INT小的值.
  否则会是MAX_INT
