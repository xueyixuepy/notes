- 题目:
  给定一个未排序的整数数组 nums ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。
  请你设计并实现时间复杂度为 O(n) 的算法解决此问题。
- 示例:
  示例 1：
  输入：nums = [100,4,200,1,3,2]
  输出：4
  解释：最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。
  示例 2：
  输入：nums = [0,3,7,2,5,8,4,6,0,1]
  输出：9
  示例 3：
  输入：nums = [1,0,1,2]
  输出：3
---
- 思路
  想不到怎么用哈希,感觉还是排序再遍历会好点
  排序是O(nlogn),遍历是n,总的是O(n+nlogn)
  如果找到比上一个数大一的,计数++
  如果找到大0的,不作为
  其他则重新计数
- 代码:
  ```cpp
  class Solution {
  public:
      int longestConsecutive(vector<int>& nums) {
          int cout = 0;
          int maxCout = 0;
          sort(nums.begin(),nums.end());
          for(int i = 0;i<nums.size();i++){
              if(i == 0){
                  cout ++ ;
                  maxCout = max(maxCout,cout);
              }
              else{
                  if(nums[i] - nums[i-1] == 1){
                      cout++;
                  }
                  if(nums[i] - nums[i-1] > 1||i==nums.size()-1){
                      maxCout = max(maxCout,cout);
                      cout = 1;
                  }
              }
          }
          return maxCout;
      }
  };
  ```
- 结果:
  时间95,空间93
---
**题解的做法(哈希表)**
- 思路:
  先把每个数放入哈希表作为key,值不重要,这主要是为了快速查找某个数是否存在
  然后遍历nums,对每个遍历到的数,设为x,不断在哈希表中查找是否存在x+1,x+2....直到不存在,得到长度为不存在的x+n减去x
  只要查作为开头的数,不然会重复
  于是排除掉x-1存在的那些数
- 代码:
  ```cpp
  class Solution {
  public:
      int longestConsecutive(vector<int>& nums) {
          unordered_set<int> num_set;
          for (const int& num : nums) {
              num_set.insert(num);
          }

          int longestStreak = 0;

          for (const int& num : num_set) {
              if (!num_set.count(num - 1)) {
                  int currentNum = num;
                  int currentStreak = 1;

                  while (num_set.count(currentNum + 1)) {
                      currentNum += 1;
                      currentStreak += 1;
                  }

                  longestStreak = max(longestStreak, currentStreak);
              }
          }

          return longestStreak;           
      }
  };
  ```
- 复杂度
  时间O(n),空间O(n)
  时间51,空间58
