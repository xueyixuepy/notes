- 题目:
  给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。
- 示例:
  示例 1:
  输入: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
  输出: [["bat"],["nat","tan"],["ate","eat","tea"]]
  解释：
  在 strs 中没有字符串可以通过重新排列来形成 "bat"。
  字符串 "nat" 和 "tan" 是字母异位词，因为它们可以重新排列以形成彼此。
  字符串 "ate" ，"eat" 和 "tea" 是字母异位词，因为它们可以重新排列以形成彼此。
  示例 2:
  输入: strs = [""]
  输出: [[""]]
---
- 思路:
  本来想着用素数来表示特征,但是可能出现100次方,所以还是只能用vector来做特征了.
  ==**注:map中key是vector的话,是会比较所有元素的,unordered_map中没有这种操作**==
  于是遍历字符串,记录每个字符串特征对应的位置,在该位置emplace_back
- 代码:
  ```cpp
  class Solution {
  public:
      vector<vector<string>> groupAnagrams(vector<string>& strs) {
          map<vector<int>,int> m;
          vector<vector<string>> res;
          for(string s:strs){
              vector<int> tem =features(s);
              if(m.count(tem)){
                res[m[tem]].emplace_back(s) ;
              }
              else{
                  res.emplace_back();
                  res.back().emplace_back(s);
                  m[tem] = res.size()-1;
              }
          }
          return res;
      }
      vector<int> features(string s){
          vector<int> f(26,0);
          for(char i:s){
              f[int(i-'a')] ++;
          }
          return f;
      }
  };
  ```
- 结果
  时间13,空间6
