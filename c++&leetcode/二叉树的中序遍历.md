# 记录
- 题目:
  给定一个二叉树的根节点 root ，返回 它的 中序 遍历 。
- 示例:
  输入：root = [1,null,2,3]
  输出：[1,3,2]
- ==中序遍历:==
  ==中序遍历（In-order Traversal） 访问顺序：左子树 → 根节点 → 右子树==
- 思路:
  递归,先递归左子树,然后对本身进行操作,再遍历右子树
  简单题,没什么好说的
- 代码:
```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<int> con;
    vector<int> inorderTraversal(TreeNode* root) {
        tool(root);
        return this->con;

    }
    void tool(TreeNode* root){
        if(root==nullptr){
            return;
        }
        else{
            tool(root->left);
            this->con.emplace_back(root->val);
            tool(root->right);
        }

    }
    
};
```
- 题目里有提到进阶任务,不用递归而用迭代,所以我试了试
  思路:使用栈,先沿着左边一个个压栈,然后取出,把值加入向量,再判断它有没有右子树,有的话把右子树压栈,在把右子树作为根沿左子树遍历压栈
  具体看代码
```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        stack<TreeNode*> st1;
        stack<TreeNode*> st2;
        vector<int> con;
        TreeNode* tem = root;
        TreeNode* tem2 = root;

        if(root==nullptr){
            return con;
        }

            while(tem!=nullptr){
                st1.push(tem);
                tem = tem->left;
            }

        while(!st1.empty()){
            tem2 = st1.top();
            con.emplace_back(st1.top()->val);
            st1.pop();
            if(tem2->right!=nullptr){
                st1.push(tem2->right);
                tem = st1.top()->left;
                while(tem!=nullptr){
                    st1.push(tem);
                    tem = tem->left;
                }

            }

        }
        return con;



    }
};
```

var inorderTraversal = function (root) {

    const stack = []
    while (root || stack.length) {
