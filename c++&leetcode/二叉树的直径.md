# 记录
- 题目：
  给你一棵二叉树的根节点，返回该树的 直径 。
  二叉树的 直径 是指树中任意两个节点之间最长路径的 长度 。这条路径可能经过也可能不经过根节点 root 。
  两节点之间路径的 长度 由它们之间边数表示。
- 思路：
  可以发现最长路径一定发生在根结点，无子结点的结点之间。
  于是递归遍历，记录这些结点。
  利用霍夫曼编码记录路径。
  然后通过一个个比较距离来找出最大路径。
- 代码如下：
  ```cpp
    /**
  * Definition for a binary tree node.
  * struct TreeNode {
  *     int val;
  *     TreeNode *left;
  *     TreeNode *right;
  *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
  *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
  *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
  * };
  */
  class Solution {
  public:
      vector<int> max;
      int m=0;
      vector<string> hfm;

      int diameterOfBinaryTree(TreeNode* root) {
          // if(this->hfm.size()==1){
          //     return hfm[1].size();
          // }

          tool(root,"");
          this->hfm.emplace_back("");
          int maxLength = 0;
          int tem = 0;
          for(int i = 0;i<hfm.size();i++){
              for(int j = 0;j<hfm.size();j++){
                  if(i!=j){
                      tem = tool2(hfm[i],hfm[j]);
                      maxLength = maxLength>tem?maxLength:tem;
                  }

              }
          }
          return maxLength;
      }
      //给末端节点计算霍夫曼编码并记录
      void tool(TreeNode* root,string h){
          if(root == nullptr){
              return ;
          }
          else{
              if(root->left == nullptr&&root->right == nullptr){
                  this->hfm.emplace_back(h);
                  return ;
              }
              if(root->left!=nullptr){    
                  tool(root->left,h+"1");
              }
              if(root->right!=nullptr){
                  tool(root->right,h+"0");
              }
          }
      }
      //根据霍夫曼码计算距离
      int tool2(string s1,string s2){
          int maxLength = s1.size()>=s2.size()?s1.size():s2.size();
          int minLength = s2.size()>=s1.size()?s1.size():s2.size();
          int i = 0;
          for(i = 0;i<minLength;i++){
              if(s1[i]!=s2[i]){
                  
                  break;
              }
          }
          return maxLength+minLength-2*(i);
      }
  };
  ```

- 他人的做法：
  - 代码如下：
    ```cpp
    class Solution {
      int maxv = 0;

    public:
      int diameterOfBinaryTree(TreeNode* root) {
          recur(root);
          return maxv;
      }

      int recur(TreeNode* root) {
          int leftl = 0, rightl = 0;
          if (root->left != nullptr)
              leftl = recur(root->left) + 1;
          if (root->right != nullptr)
              rightl = recur(root->right) + 1;
          maxv = max(leftl + rightl, maxv);
          return max(leftl, rightl);
      }
    };
    ```
    - 解析：
      反过来想，路径最长的两个结点，他们会有一个最低公共祖先结点，他们位于公共祖先的左右两侧，（不可能在一侧，那样的话不是最低的公共祖先了），毫无疑问，他们也得是这个祖先左右两侧最深的结点，（不可能有更深的了，否则，路径最长的结点就是其他的结点），那么，如何计算路径长度，就是计算这个最低公共祖先的左右子树深度之和。
      因此，只需要遍历树的每个结点，计算他们左右子树深度和，找出最大的和就好。
      对于这个代码
      ```cpp
      int recur(TreeNode* root) {
          int leftl = 0, rightl = 0;
          if (root->left != nullptr)
              leftl = recur(root->left) + 1;
          if (root->right != nullptr)
              rightl = recur(root->right) + 1;
          //maxv = max(leftl + rightl, maxv);
          return max(leftl, rightl);
      }
      ```
      这一部分，去掉注释的部分，就是一个计算深度的函数，对于root结点，会遍历其左右子树，找出最深深度，故而，恰巧
      ```cpp 
      recur(root->left);
      ```
      是计算左结点的深度。
      ```cpp
      recur(root->right);
      ```
      是计算右结点的深度。
      加上1就是当前结点的左子树和右子树深度。
      注释掉的部分全局记录最大左右子树深度和。

      时间击败100%，空间20%
