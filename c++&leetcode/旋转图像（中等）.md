# 记录
- 题目
  给定一个 n × n 的二维矩阵 matrix 表示一个图像。请你将图像顺时针旋转 90 度。
  你必须在原地旋转图像，这意味着你需要直接修改输入的二维矩阵。请不要使用另一个矩阵来旋转图像。
  - 示例
    输入：matrix = \[[1,2,3],[4,5,6],[7,8,9]]
    输出：\[[7,4,1],[8,5,2],[9,6,3]]


- 我的解法是依据了同样类型的某一题，这题和那题一样，都是要从外圈到内圈，每圈的行为是一样的。所以需要定义四个变量left，right，top，bottom来定位每一圈。
- 于是我的初始代码为
  ```cpp
  class Solution {
    public:
        void rotate(vector<vector<int>>& matrix) {
            int tem1;
            int tem2;
            int left = 0;
            int right = matrix[0].size()-1;
            int top = 0;
            int bottom = matrix.size()-1;
            while(left<=right&&top<=bottom){
                for(int i = left;i<=right;i++){
                    tem1 = matrix[i][right];
                    matrix[i][right] = matrix[top][i];
                    tem2 = matrix[bottom][right-i];
                    matrix[bottom][right-i] = tem1;
                    tem1 = matrix[bottom-i][left];
                    matrix[bottom-i][left] = tem2;
                    matrix[top][i] = tem1;

                }
                left++;right--;top++;bottom--;
            }

        }
    };
  ```
- 然而解答出错了,这时我发现因为例子里的最大是个2x2,所以我误解的i的意义,这里的i是全局的而非局部的,故而bottom-i表示的位置是错的,应该是matrix.size()-1-i;而right-i则应该是matrix[0].size()-1-i
- 然后又发现,其实i不能遍历到right
- 最终结果为
  ```cpp
  class Solution {
    public:
        void rotate(vector<vector<int>>& matrix) {
            int tem1;
            int tem2;
            int left = 0;
            int right = matrix[0].size()-1;
            int top = 0;
            int bottom = matrix.size()-1;
            while(left<=right&&top<=bottom){
                for(int i = left;i<right;i++){
                    tem1 = matrix[i][right];
                    matrix[i][right] = matrix[top][i];
                    tem2 = matrix[bottom][matrix[0].size()-1-i];
                    matrix[bottom][matrix[0].size()-1-i] = tem1;
                    tem1 = matrix[matrix.size()-1-i][left];
                    matrix[matrix.size()-1-i][left] = tem2;
                    matrix[top][i] = tem1;

                }
                left++;right--;top++;bottom--;
            }

        }
    };
  ```
- 应该就是接近优解了,时间击败100%,空间没有,还能在临时变量处做修改.
- 发现一个更好的解法,利用了转置
    - 执行用时：0 ms, 在所有 C 提交中击败了100.00%的用户
    - 内存消耗：6.1 MB, 在所有 C 提交中击败了84.84%的用户
    **情况一**：顺时针转 90 度：先转置再左右镜像
    1 2 3         --      7 4 1
    4 5 6         --      8 5 2
    7 8 9         --      9 6 3
    **情况二**：顺时针转 180 度:先上下镜像，再左右镜像（先左右再上下也可）
    1 2 3         --      9 8 7
    4 5 6         --      6 5 4
    7 8 9         --      3 2 1
    **情况三**：顺时针转 270 度：先转置再上下镜像
    1 2 3         --     3 6 9
    4 5 6         --     2 5 8
    7 8 9         --     1 4 7
    ```cpp
    void rotate(int** matrix, int matrixSize, int* matrixColSize){
        //先转置矩阵
        for (int i = 0; i < matrixSize; ++i)
            for (int j = 0; j < i; ++j){
                int temp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = temp;
            }
        
        //再镜像对称
        int left = 0;
        int right = matrixSize - 1;
        while (left < right){
            for (int i = 0; i < matrixSize; ++i){
                int temp = matrix[i][left];
                matrix[i][left] = matrix[i][right];
                matrix[i][right] = temp;
            }
            left++;
            right--;
        }   
    }
    ```
