# 记录
- 题目：
  给你二叉树的根结点 root ，请你将它展开为一个单链表：
  展开后的单链表应该同样使用 TreeNode ，其中 right 子指针指向链表中下一个结点，而左子指针始终为 null 。
  展开后的单链表应该与二叉树 先序遍历 顺序相同。
- 思路：
  我的想法是先序遍历记录到vector里，然后一个个连，做到是做出来了，时间挺好，空间差点，但是，这题似乎应该用其他方法
- 代码：
  ```cpp
    /**
  * Definition for a binary tree node.
  * struct TreeNode {
  *     int val;
  *     TreeNode *left;
  *     TreeNode *right;
  *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
  *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
  *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
  * };
  */
  class Solution {
  public:
      vector<TreeNode*>  v;
      void flatten(TreeNode* root) {
          tool(root);
          TreeNode* pre = new TreeNode;
          TreeNode* tem = pre;
          for(int i = 0;i < v.size();i++){
              tem->left = nullptr;
              tem->right = v[i];
              tem = v[i];
          }
          tem->left = nullptr;
          tem->right = nullptr;
      }
      void tool(TreeNode* root){
          if(root==nullptr) return;
          this->v.emplace_back(root);
          tool(root->left);
          tool(root->right);
      }
  };
  ```
- 结果：
  还行，但是！！！
  有进阶要求：
  **进阶：你可以使用原地算法（O(1) 额外空间）展开这棵树吗？**
- 新的思路：
  可以发现，以先序顺序，只需要把每个结点的右子树接在左子树（如果有左子树）的先序遍历的最后结点上（先序遍历其实是有要求先跟先左后右的），然后把结点的左子树移到右边，左子树置空即可。
  于是我写了一个工具函数，用于查找结点先序遍历的最后子树。
  然后再先序递归原地修改。
  感觉其实时间花的更多了，毕竟会遍历每个结点外加上部分结点的左子树。
- 代码：
  ```cpp
  /**
  * Definition for a binary tree node.
  * struct TreeNode {
  *     int val;
  *     TreeNode *left;
  *     TreeNode *right;
  *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
  *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
  *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
  * };
  */
  class Solution {
  public:
      TreeNode* pre;
      void flatten(TreeNode* root) {
          if(root == nullptr) return;
          TreeNode* lastRight = tool(root->left) ;
          if(lastRight != nullptr){
              lastRight->right = root->right;
              root->right = root->left;
              root->left = nullptr;
          }

          flatten(root->left);
          flatten(root->right);
      }
      TreeNode* tool(TreeNode* root){
          if(root==nullptr) return nullptr;
          
          tool(root->left);
          TreeNode* lastRight = tool(root->right);
          if(lastRight == nullptr){
              return root;
          }
          else{
              return lastRight;
          }
      }
  };
  ```
- 结果：
  时间100%，空间50%
- 他人的思路
  依旧递归：
  但是在返回的时候进行操作，所以遍历顺序要反着来，先右后左最后根，
  代码：
  ```cpp
  class Solution {
  public:
      TreeNode* last = nullptr;
      void flatten(TreeNode* root) {
          if (root == nullptr) return;
          flatten(root->right);
          flatten(root->left);
          root->right = last;
          root->left = nullptr;
          last = root;
      }
  };
  ```
  非常简洁了，时间空间都很好。

- 他人的做法2
  依旧递归，和我的第二种做法异曲同工
  代码：
  ```cpp
  class Solution { 
      public void flatten(TreeNode root) {
          if (root == null)
              return;

          if (root.left != null) {
              TreeNode left = root.left;
              TreeNode right = root.right;
              TreeNode cur = left;
              while (cur.right != null) {
                  cur = cur.right;
              }
              cur.right = right;
              root.left = null;
              root.right = left;
          }

          flatten(root.right);
      }
  }
  ```
  我真傻，真的，找到左子树的最右下角结点只需要一直遍历左结点的右子树就好了其实。
