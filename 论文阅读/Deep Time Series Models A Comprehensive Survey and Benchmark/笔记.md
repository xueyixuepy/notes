### 一.时间序列概念
- 时序数学定义：\(X\in\mathbb R^{T\times C}\)，T时间步，C变量数。
- 建模两大核心：**时间依赖 Temporal Dependency、变量依赖 Variate Correlation**。
  - 时间依赖
    时间依赖：鉴于时间序列数据固有的序列特性，一种明显的技术范式是捕捉一组历史数据的时间依赖关系。本质上，时间依赖指的是不同时间点或子序列之间存在的复杂关联。
  - 变量依赖 
    变量相关性：除时间依赖外，理解不同变量间的相关性对于分析多变量时间序列至关重要，尤其是在高维场景下。这些相关性包含了多个测量值随时间变化的复杂交互与关联。阐明这些关系可为理解潜在动态和隐含过程提供重要见解。
### 二.时间序列分析
四大下游任务：
1. **预测 Forecasting**：历史→未来；分长期预测、短期预测；
2. **补全 Imputation**：利用上下文恢复缺失时间步；
3. **异常检测 Anomaly Detection**：识别异常时间点；
4. **分类 Classification**：整条时序打类别标签。
### 三.基础模块
#### 1 平稳化 Stationarization
现实时序普遍非平稳（均值方差随时间漂移）。
- 传统方法：差分、对数变换；
- 深度学习：
  - DAIN：自适应输入归一化；
  - RevIN：可逆实例归一化，带可学习仿射变换；
  - Non‑Stationary Transformer：无额外参数，输入标准化，输出反归一化恢复原始统计量；
  - SAN：不对整条序列归一化，对切片做归一化，增加统计量预测模块。
>**时序预测高频必用模块，大量 SOTA 预测模型都接入平稳化模块，解决分布偏移**。
#### 2 分解 Decomposition（三类）
1）季节‑趋势分解 Seasonal‑Trend Decomposition
Autoformer 首次将分解块嵌入深度网络：平均池化提取趋势分量\(X_{\mathcal T}\)，原序列减去趋势得到季节分量\(X_{\mathcal S}\)。
> 这个分解块被 InParformer、Preformer 大量后续预测模型复用。

2）基扩展 Basis Expansion
- N‑BEATS：分层回代预测 backcast + 向前预测 forecast，每一块去除已经拟合好的信号，各块预测结果求和；
- N‑HiTs：增加子采样层，多频率采样提升预测；
- DEPTS、DEWP：引入周期隐状态，面向周期性多变量时序。

3）矩阵分解 Matrix Factorization，面向多变量时序
把\(T\times C\)时序矩阵分解为两个低秩矩阵乘积。
TRMF、NoTMF、BTF、DeepGLO、LSTM‑GL‑ReMF，增加时间 / 空间正则项，捕捉时空关联。
#### 3 傅里叶分析 Fourier Analysis
分**时域建模、频域建模**两大路线。
1）时域建模（FFT 做工具，模型仍然在时域运算）
- TimesNet：FFT 提取振幅最大的主导频率，一维时序重塑为二维张量，同时建模周期内、周期间变化；
- Autoformer：Wiener‑Khinchin 定理，用 FFT 高效实现自相关机制，替代自注意力，用于长序列预测；
- FEDformer：不只保留低频，随机选取部分傅里叶分量，兼顾高低频；
- FITS：低通滤波器过滤高频，压缩模型规模。

2）频域建模（直接变换到频域空间做网络运算）
STFNet、StemGNN、EV‑FGN、FreTS、TSLANet、FourierDiffusion；
FreTS：DFT 转到频域，复数分开实部虚部，用频域 MLP 做时序预测。
### 四.模型架构
#### 1 MLP‑based 基于多层感知机

代表：N‑BEATS，N‑HiTs，DLinear，TSMixer，FITS，TiDE，Koopa，TimeMixer

- DLinear：非常简单的线性层，**长时序预测效果出人意料的强，参数量小速度快**；
- TiDE：专门引入外生变量，只适合预测任务；
- Koopa：基于 Koopman 理论，支持在线更新；

> 优点：训练推理效率极高；缺点：缺少复杂高阶表征，在分类、异常检测任务表现一般。适合算力受限的**时序预测场景**。

#### 2 RNN‑based（包含 SSM、Mamba、Neural ODE）基于循环神经网络

代表：LSTNet、DA‑RNN、DeepAR、DSSM、S4、**Mamba**、Neural‑ODE

- DeepAR：经典概率时序预测，输出概率分布，可利用协变量；
- S4 / Mamba：结构化状态空间模型 SSM，序列长度线性复杂度；Mamba 对长序列能力很强；
- Neural ODE：面向**不规则采样时序预测**，把 RNN 扩展到连续时间；

> 短板：原生 RNN 类对于超长的长时序预测，弱于 Transformer；更适合短期预测、概率预测、不规则时序。

#### 3 CNN‑based 基于卷积神经网络

代表：TCN、WaveNet、SCINet、MICN、ModernTCN、**TimesNet**

- TCN：空洞卷积扩大感受野，但感受野仍有上限；
- TimesNet：1D 转 2D Inception 卷积，**通用模型，预测 / 补全 / 分类 / 异常检测全部任务都可以取得不错效果**；

> 代价：多尺度卷积带来更大计算开销，训练推理速度慢。

#### 4 GNN‑based 基于图神经网络

代表：DCRNN、STGCN、GraphWaveNet、AGCRN、MTGNN、StemGNN、MSGNet、TimeFilter
核心思想：多元时序的每个变量视为图节点；分为两类：①需要预先给定图结构；②模型自动学习邻接矩阵。

- TimeFilter：预测任务表现突出；MSGNet 在异常检测效果好；

> 优势：擅长挖掘多变量之间复杂依赖；局限：**通用性弱，很难做到一个模型通吃全部四类任务**。

#### 5 Transformer‑based（时序预测最重要架构）基于Transformer

按照 token 粒度分为点 Point‑wise、块 Patch‑wise、序列 Series‑wise（图 7）。
1）Point‑wise 点粒度，每个时间步作为 token
代表：Informer、Non‑Stationary Transformer
问题：原始自注意力\(O(T^2)\)复杂度；改进 ProbSparse Attention、LogSparse、Pyraformer 金字塔注意力。嵌入层 = 数值投影 + 位置编码 + 时间戳编码。

> 早期长序列预测主流，现在逐步被 patch/series‑wise 替代。

2）Patch‑wise 块粒度，连续时间步打包成 patch 作为 token
代表：PatchTST、Crossformer、Pathformer
PatchTST：时序切分重叠 patch，每个 patch 做嵌入；通道独立设计，长时序预测效果优秀；
Crossformer：双阶段注意力，跨时间、跨维度，捕捉变量之间 patch 依赖。

> token 数量大幅下降，计算开销显著降低，是现在预测热门方案。

3）Series‑wise 序列粒度，**iTransformer**
把每个变量整条时序作为一个 token，反转时间和变量维度，原生适配多变量时序；直接使用标准 Transformer，不需要修改注意力。

> 在 TSLib 基准中**长时序预测 SOTA**。TimeXer 结合 patch‑wise、series‑wise，专门处理外生变量预测。

### 五.时序基础模型 TSFM Section V（时序预测新方向）
两类：

1. 时序原生基础模型：从零基于时序数据预训练；MOMENT、Moirai‑MoE、TTMs、TimesFM、Sundial、Chronos2；
2. LLM 改造而来：GPT4TS、Lag‑LLaMA、LLMTime。

目标：**零样本预测 Zero‑shot forecasting，不需要下游微调直接预测**。
实验发现：

- 增大输入上下文一般提升零样本预测；
- 但不是无限增大，过长输入引入噪声会性能下降（Sundial 2880 输入优于 8192 输入）；
- 部分数据集在预训练阶段被 TSFM 见过，造成评测泄露，实验需要规避数据集泄露。

### 一.Transformer

- 定位：**序列建模主干架构（骨架）**，核心：自注意力，抛弃 RNN 串行循环
- 自注意力 Self-Attention：QKV，所有 token 直接交互，捕捉全局依赖；多头 = 多视角提取特征
- 必备：**位置编码**，模型本身不识先后顺序
- 基础单元：多头注意力 + FFN + 残差 + 层归一化
- 结构：Encoder（时序预测大多只用 Encoder）、Decoder（自回归生成）
- 时序 3 类变体（同属 Transformer 架构，仅 token 划分不同）
  1. Point-wise：单时间步为 token，代表 Informer；开销大
  2. Patch-wise：一段时序打包成 patch，代表 PatchTST；均衡速度与精度
  3. Series-wise：单个变量整条时序为 token，代表 iTransformer；多变量长预测强
- 和之前概念：Transformer = 架构；RevIN / 分解 / FFT = 可插拔基础模块
- 优缺点
  并行训练、擅长长距离依赖，时序预测上限高
  原版注意力\(O(T^2)\)，长序列算力成本高；小数据易过拟合

### 时序预测
时序预测本质：**用过去一段历史窗口，去预测未来连续的值**。
数学形式：
输入 \(X_{[t-L:t]}\)（回看窗口，look-back length，长度 L）
输出 \(\hat Y_{[t+1:t+H]}\)（预测长度 horizon，H）
整体分成 6 大步：**数据处理 → 可选时序模块增强 → 选模型架构主干 → 任务头 + 损失 → 训练验证调参 → 推理预测**
- 4.接上【预测任务头】+ 损失函数
  主干输出隐向量之后，**预测头把隐向量映射成 H 个未来时间步**。
   - 确定性预测（输出一个数值）：损失一般 MSE、MAE，最常用
   - 概率预测（输出分布，适合金融、风险场景）：DeepAR，输出高斯分布，损失用 NLL 负对数似然
  > 对比分类头：分类头输出类别 logits；预测头输出连续时序值。

- 5.训练、验证、调参
   1. 时序验证：时间顺序划分，比如前 70% 训练，中间 10% 验证，后 20% 测试
   2. 评价指标（TSLib 标准）
      - MSE、MAE：长时序确定性预测
      - SMAPE、MASE：短期 M4 竞赛
   3. 重点超参：look_back、pred_len、batch size、学习率
- 6.推理
  推理时：拿最新 L 个历史数据，送入模型，一次性输出未来 H 步。
  两种推理模式：
  - **一次性预测（直接多步预测，直接输出 H 步）**：iTransformer、PatchTST 主流做法，误差不会迭代累积
  - **递归预测（预测一步，把预测结果放回输入再预测下一步）**：容易误差越滚越大，长预测不推荐
